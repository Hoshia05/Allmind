# Allmind

"스트리머 통합 지원 시스템, 올마인드 입니다."

2PC 방송 환경을 위한 통합 대시보드입니다. **방송 PC**에서 `Allmind.exe` 하나만 실행하면, 메인 PC·아이패드·폰에서는 브라우저로 주소만 열어 쓰면 됩니다. OBS(obs-websocket)와 치지직을 연결해 방송 중 필요한 것들을 한 화면에 모았습니다.

## 다운로드

**[➡ 최신 버전 받기 (Releases)](../../releases/latest)** — `Allmind-x.y.z.exe` 파일 하나만 받으면 됩니다. 설치도, Node.js도 필요 없습니다. (Windows 10/11, 64비트)

처음 한 번만 받으면 됩니다. 이후 새 버전은 앱 안의 [업데이트](#업데이트) 기능으로 설치해요. 예전 버전이 필요하면 [Releases](../../releases) 목록에서 받을 수 있습니다.

> 예전 이름: Stream Desk → Arkbird → **Allmind**(0.20.0~). 예전 릴리스에 같이 올라가 있는 `Arkbird-x.y.z.exe`는 옛 버전 업데이트용 같은 파일이었고, 0.30.1부터는 올리지 않아요.

처음 실행하면 Windows가 *"Windows의 PC 보호"* 창을 띄울 수 있습니다. 코드 서명이 없는 프로그램이라 그렇습니다. **추가 정보 → 실행**을 누르세요.

## 기능

- **방송 화면 / 영도 탭**: OBS가 그리는 화면(방송 화면 또는 영도)을 그대로 보여 줍니다. 영도는 클릭·마우스 이동·스크롤 전달과 **광고 스킵**(수동/자동)을 지원하고, 영도가 재생되면 자동으로 영도 탭으로 넘어갑니다(**자동 전환** 스위치로 끌 수 있어요). 영도가 멈췄으면 **↻**로 브라우저 소스를 새로고침하고, **⤢**(또는 `F`)로 전체 화면을 쓸 수 있어요. 화질은 가볍게(30fps)/부드럽게/균형/고화질(최대 60fps)/무손실(PNG) 중 선택.
- **BGM 셋리스트**: 음악 폴더를 OBS로 재생합니다. 순서·셔플·한 곡 반복, 곡 순서 변경, 검색, 재생 위치 이동, 볼륨 조절을 지원하고, 폴더에 곡을 넣으면 **↻**로 다시 읽을 수 있어요. 음악 파일에 들어 있는 앨범 커버는 자동으로 빼고 재생해서(원본 파일은 그대로) 화면에 그림이 뜨거나 OBS 오디오 지연이 쌓이지 않습니다.
- **사운드보드**: 효과음 폴더의 파일마다 버튼이 생겨요. 누르면 바로 재생, 재생 중인 버튼을 다시 누르면 정지. 폴더에 파일을 넣으면 자동으로 추가돼요.
- **영도 자동 일시정지**: 영도 소리가 나면 BGM을 멈추거나 볼륨을 낮췄다가 끝나면 되돌립니다. 첫 알림 소리부터 영상이 끝날 때까지 끊김 없이 유지됩니다(**첫 알림 후 유지** 슬라이더). 설정은 음악 패널의 **자동정지** 탭에 있어요.
- **채팅 · 후원 · 위플챗**: 치지직 채팅(이모티콘, 후원/영도/구독 강조), 이번 방송의 후원·영도·미션·구독 목록(읽음 표시와 **모두 읽음**, 재시작해도 유지), 위플챗 패널(패널 크기에 맞게 늘어납니다).
- **시청자 정보**: 채팅이나 후원 목록에서 닉네임을 누르면 그 시청자의 채팅 수, 최근 채팅, 후원·구독 기록(Allmind가 켜진 뒤 본 것)과 치지직 채널 링크가 나와요.
- **방송 준비**: 치지직 제목·카테고리·태그, 유튜브 아카이브 제목, 녹화 파일 이름을 한 곳에서 정하고 한 번에 적용해요. 유튜브 제목·파일 이름은 치지직 제목을 따라가다가, 직접 고치면 따로 정할 수 있어요. ([연동](#연동-유튜브-아카이브--드라이브--치지직) 참고)
- **유튜브 아카이브 지키기 · 드라이브 자동 업로드**: 방송마다 **비공개** 유튜브 아카이브를 미리 준비하고 방송 중에 지켜요. 녹화가 끝나면 영상과 마크 파일을 `날짜 - 제목` 이름으로 구글 드라이브의 **원하는 폴더**에 올려요.
- **Xylem (시청자 참여)**: **치즈 룰렛**과 대기 화면 미니게임 **공중전**. 전용 창에서 관리하고, **방송 중에도** Allmind를 다시 켜지 않고 업데이트돼요. ([Xylem](#xylem-시청자-참여-치즈-룰렛--공중전) 참고)
- **스트림덱**: Allmind 플러그인으로 BGM·사운드보드를 스트림덱 키로 조작하고, 재생 중인 곡·사운드가 키에 보여요. ([스트림덱](#스트림덱-bgm--사운드보드) 참고)
- **알림 화면**: 도네 알림 소스를 방송에 나가는 모습 그대로 확인.
- **방송 상태**: LIVE/OFFLINE, 시청자 수와 추이, 최고 시청자, 방송 시간, 제목, 비트레이트·드롭 프레임·인코딩/렌더 지연.
- **스튜디오 조작**: OBS 장면 전환 버튼, 마이크 음소거와 레벨 미터, ■ 정지 / 넘기기 / 알림 정지 (치지직 리모콘 버튼).
- **터치 기기 대응**: 아이패드·폰(Z 폴드 등)에서도 쓸 수 있게 세로 화면 레이아웃과 하단 탭(채팅·음악·알림 화면)을 지원합니다. 아래 **이 기기 설정**도 참고하세요.
- **⭐ 마크 + 💬 채팅 로그**: 방송 중 웃긴 순간에 버튼 하나로 녹화 파일에 표시. 녹화하는 동안의 치지직 채팅도 영상과 같은 시간대로 함께 저장돼서, 나중에 유튜브 편집할 때(SkyEye) 하이라이트 후보의 근거가 됩니다. 폰·아이패드·스트림덱으로도 누를 수 있어요.
- **OBS 부하 보호**: OBS가 프레임을 놓치기 시작하면 미러링 fps를 자동으로 낮춰 방송에 영향을 주지 않습니다.
- **바로가기 링크**: 상단 오른쪽에 **치지직 스튜디오 · 채팅 팝업 · 내 방송**이 채널 주소로 자동 만들어집니다. **채팅 팝업**은 대시보드 옆에 좁은 창으로 열려요. 링크를 더 넣으려면 [고급 설정](#고급-설정-configjson)의 `links`를 쓰세요.
- **이 기기 설정 (⚙)**: 상단의 ⚙ 버튼에서 기기(브라우저)마다 따로 저장되는 설정을 바꿉니다.
  - **데이터 절약**: 화면 미러링을 최대 15fps로 제한. 폰에서는 처음부터 켜져 있어요.
  - **화면 꺼짐 방지**, **버튼 진동**(진동을 지원하는 기기만)
  - **채팅 글자 크기**: 가− / 가+ / 100%
  - **치지직 리모콘 열기**, **레이아웃 초기화**
- **트레이 아이콘 · 설정 창**: 방송 PC 작업표시줄 트레이의 Allmind 아이콘을 누르면 설정 창이 열리고, 오른쪽 클릭 메뉴에서 **Allmind 열기 / 대시보드 열기 (이 PC) / Xylem 열기 / 종료**를 고를 수 있어요. Allmind를 한 번 더 실행하면 새로 켜지지 않고 켜져 있는 것의 설정 창이 열립니다. 설정 창은 OBS 비밀번호가 들어 있어서 **방송 PC에서만** 열려요(메인 PC·폰에서는 막혀 있습니다).
- **로그 보내기**: 설정 창의 **로그 보내기** 버튼을 누르면 Allmind 로그와 OBS 최근 로그 3개(+충돌 보고서)를 zip 하나로 바탕화면에 만들어요. 비밀번호·토큰은 빠집니다. 방송이 끝난 뒤 문제를 살펴보거나(드롭 프레임, OBS 지연, 연결 끊김 등) 문제가 생겼을 때 이 파일만 보내 주세요.
- **설정 옮기기**: 설정·로그인·셋리스트 순서·랭킹 등을 **내가 정한 비밀번호로 암호화한 파일** 하나로 내보내고, 다른 PC의 Allmind에서 그대로 가져와요. ([설정 옮기기](#설정-옮기기-다른-pc로) 참고)
- **자동 업데이트 알림**: 새 버전이 나오면 알려 주고, 버튼 한 번으로 설치합니다. ([업데이트](#업데이트) 참고)

## 설치 (방송 PC, 처음 한 번)

1. `Allmind-x.y.z.exe`를 아무 폴더에 두고 실행합니다. 설정은 `%APPDATA%\Allmind`에 저장되어 버전을 바꾸거나 exe 위치를 옮겨도 그대로예요.
   - 다른 PC에서 쓰던 설정이 있다면 [설정 옮기기](#설정-옮기기-다른-pc로)로 가져오세요.
   - 방화벽 창이 뜨면 **개인 네트워크**를 허용하세요(메인 PC에서 접속하려면 필요).
   - **작업표시줄에 고정**: Allmind 창(설정 창 또는 대시보드)을 연 상태에서 작업표시줄의 Allmind 아이콘을 오른쪽 클릭 → **작업 표시줄에 고정**하세요. Edge가 아니라 Allmind 아이콘·이름으로 고정되고, 업데이트해도 계속 동작합니다. (창은 Edge의 앱 모드로 열리지만, 작업표시줄에는 Allmind로 표시되게 해 둡니다. 안 되면 `%LOCALAPPDATA%\Allmind\Allmind.exe`를 직접 고정해도 돼요.) 이 파일은 실행할 때마다 최신 버전으로 갱신됩니다.
2. 창이 열리면 **설정**을 채웁니다.
   - **WebSocket 비밀번호**: OBS → *도구 → WebSocket 서버 설정*에서 서버를 켜고 *연결 정보 표시*의 비밀번호를 복사.
   - **OBS 소스 이름**: 영도·위플챗 소스를 목록에서 선택(마이크 소스는 비워 두면 OBS의 기본 마이크).
   - **음악 폴더**: **찾아보기**로 BGM 폴더 선택.
   - **사운드보드 폴더** (선택): 짧은 효과음 파일이 든 폴더.
   - **치지직 채널 주소**: 채널 링크 붙여넣기.
   - 그 밖에 **OBS 위치**(비워 두면 자동으로 찾아요), **Allmind를 켤 때 OBS도 같이 켜기**, **Windows 시작 시 자동 실행**, 서버 **포트**(기본 8080, 보통 그대로)가 있어요.
   - **저장하고 다시 시작**.
3. OBS를 닫은 상태에서 **OBS 시작**을 누릅니다. 클릭 전달·광고 스킵을 쓰려면 OBS를 Allmind로 켜야 합니다. 이후로는 자동입니다.
4. 대시보드에서 **현재 장면에 만들기**로 BGM 소스를 만들고, OBS에서
   - `BGM Player`를 BGM 트랙에 지정(*편집 → 고급 오디오 속성*)
   - 모든 장면에 추가(**+ → 미디어 소스 → 기존 항목 추가**). OBS는 활성 장면의 오디오만 재생합니다.
5. (선택) **■ 정지 / 넘기기 / 알림 정지**: OBS **독 → 사용자 지정 브라우저 독…**에 Allmind에 표시된 리모콘 주소를 추가하고, 그 독에서 네이버에 로그인한 뒤 독을 열어 둡니다.

사운드보드를 쓴다면 대시보드의 사운드보드 칸에서 **만들기**를 누르세요. `Soundboard` 미디어 소스가 BGM 소스가 있는 장면마다 추가되고, 오디오 트랙·모니터링 설정도 BGM과 똑같이 맞춰져요.

**Windows 시작 시 자동 실행**을 켜면 로그인할 때 트레이에서 조용히 시작합니다.

### 업데이트

새 버전이 나오면 방송 PC의 설정 창 **업데이트** 칸과 대시보드 위쪽에 알림이 떠요(6시간마다 GitHub를 확인합니다). 설정 창에서 **지금 업데이트**를 누르면 새 exe를 받아서 검증한 뒤 스스로 교체하고 다시 시작해요. 설정은 그대로 유지됩니다.

- 업데이트가 끝나면 **처음 실행했던 exe 파일(다운로드 폴더의 `Allmind-0.xx.x.exe` 등)도 새 버전으로 바뀌어요.** 같은 이름·같은 위치 그대로라서 바로가기도 계속 쓸 수 있고, 다음에 그 파일을 열어도 최신 버전이 시작돼요. (파일 이름의 숫자는 그대로일 수 있으니 실제 버전은 설정 창에서 보세요. 이름은 직접 `Allmind.exe` 로 바꿔도 돼요.)
- 자동으로 설치하지 않아요. 직접 눌러야만 설치됩니다.
- **방송 중이거나 녹화 중에는 설치할 수 없어요.** 끝난 뒤에 눌러 주세요.
- 확인 자체를 끄려면 설정 파일의 `update.check`를 `false`로 바꾸세요.

## 고급 설정 (config.json)

대부분은 설정 창과 대시보드에서 바꿀 수 있고, 아래는 파일을 직접 고쳐야 하는 것들입니다. 설정 창 **관리 → 기타**의 **설정 폴더 열기**로 폴더를 열고 `config.json`을 고친 뒤 Allmind를 다시 시작하세요. (파일에는 바꾼 항목만 있으면 되고, 나머지는 기본값이 쓰입니다.)

| 항목 | 설명 |
|---|---|
| `server.port` / `server.host` | 접속 포트(기본 `8080`)와 열어 줄 주소(기본 `0.0.0.0` = 같은 네트워크 전체). |
| `app.openWindowOnStart` | 시작할 때 설정 창을 띄울지(기본 `true`). Windows 시작 시 자동 실행으로 켜질 때는 원래 창을 띄우지 않아요. |
| `app.startObs` | Allmind를 켤 때 OBS도 같이 켜기 (설정 창의 같은 이름 항목). |
| `update.check` | `false`면 새 버전 확인을 끕니다. |
| `links` | 상단 링크 추가: `[{ "name": "내 링크", "url": "https://…" }]`. `"popup": true`를 넣으면 옆 창으로 열려요. |
| `chzzk.pollSeconds` / `chzzk.chatHistory` | 방송 상태 확인 간격(초, 최소 5)과 보관하는 채팅 수(기본 300). |
| `bgm.extensions` / `bgm.defaultVolumeDb` | 음악으로 인식할 확장자와 처음 볼륨(기본 -20 dB). |
| `soundboard.volumeDb` | 사운드보드 처음 볼륨(기본 -10 dB). 한 번 조절한 뒤에는 저장된 값이 쓰여요. |
| `autoPause.*` | 영도 자동 일시정지: `mode`(`pause` 멈춤 / `duck` 볼륨 낮춤), `thresholdDb`(감지 기준), `triggerMs`, `resumeAfterMs`(재개 대기), `introHoldMs`(첫 알림 후 유지), `duckDb`. 대부분 음악 패널의 **자동정지** 탭에서도 바꿀 수 있어요. |
| `interact.debugPort` | Allmind가 OBS 브라우저 소스에 접속하는 디버깅 포트(기본 `9222`). Allmind가 켜는 OBS는 항상 `9222`를 쓰니, OBS를 직접 다른 포트로 켜는 경우가 아니면 바꾸지 마세요. |
| `interact.autoSkipAds` / `interact.skipSelectors` | 광고 자동 스킵 기본값과, 스킵 버튼을 찾는 선택자 목록. 유튜브 화면이 바뀌어 스킵이 안 되면 여기에 선택자를 추가하세요. |
| `viewer.chatFps` | 위플챗 화면 미러링 fps(기본 6). |
| `xylem.packUrl` | Xylem 팩을 받아 오는 곳(기본: 이 저장소의 `public/xylem/`). 보통 바꾸지 않아요. |

3. 아이패드/폰은 Safari·Chrome으로 주소를 열고 **홈 화면에 추가**하면 전체 화면 앱처럼 쓸 수 있습니다.

## ⭐ 마크 (유튜브 편집용)

OBS가 **녹화 중**일 때 상단 바에 노란 **★ 마크** 버튼이 나타납니다. 웃긴 순간에 누르기만 하면 됩니다. 창이 뜨지 않으니 방송을 방해하지 않아요.

- **누르는 방법**
  - 대시보드의 **★ 마크** 버튼 (키보드 단축키를 켰다면 `M`)
  - 스트림덱: `/deck/mark` 주소 ([스트림덱](#스트림덱-bgm--사운드보드) 참고)
  - 폰·아이패드: `http://<방송 PC 주소>:8080/mark` 를 열면 큰 버튼 하나짜리 페이지가 나옵니다. 홈 화면에 추가해 두면 편해요.
  - 단축키(메인 PC): `POST http://<방송 PC 주소>:8080/api/mark` 요청 하나면 됩니다. 메모를 같이 보내려면 `{"label":"메모"}`.
    AutoHotkey v2 예시 (Ctrl+Alt+M):
    ```ahk
    ^!m:: {
      req := ComObject("WinHttp.WinHttpRequest.5.1")
      req.Open("POST", "http://192.168.0.10:8080/api/mark", false)
      req.Send()
    }
    ```
- **메모**: **▾** 버튼(또는 /mark 페이지)의 목록에서 각 마크에 메모를 적을 수 있어요. 녹화가 끝난 뒤에도 됩니다.
- **저장**: 마크는 누를 때마다 바로 저장됩니다. 녹화가 끝나면 영상 옆에 **`<영상 이름>.markers.json`** 파일이 생겨요. 마크도 채팅도 없는 녹화는 파일을 만들지 않습니다.
- **💬 채팅 로그**: 녹화 중에 받은 채팅·후원(·구독)을 영상 시간(`t`, 초) 기준으로 같은 파일의 `chat` 목록에 저장합니다(파일 형식 v2, 닉네임·역할·내용만, ID는 저장 안 함). 일시정지한 시간은 빠지고, 1분마다 OBS 시계와 대조해 어긋남을 바로잡아요. 15초마다(새 채팅이 있을 때만) 저장하고, Allmind를 다시 켜도 이어서 기록합니다. 설정 창 **치지직 채널** 칸의 **채팅 로그 저장 (SkyEye용)** 으로 끌 수 있어요(끄면 예전처럼 마크만 저장). 이제 마크를 한 번도 안 눌러도 채팅이 있으면 방송마다 파일이 생기니, 영상과 함께 올려 주세요.
- **업로드**: [드라이브 자동 업로드](#연동-유튜브-아카이브--드라이브--치지직)를 켜 두면 영상과 함께 같은 폴더에 자동으로 올라가요. 직접 올릴 때는 영상과 **같은 구글 드라이브 폴더**에 올려 주세요. 영상 이름을 바꿔도 괜찮아요(SkyEye가 길이로 찾아냅니다).

**추천 OBS 설정**: *설정 → 출력 → 녹화 → 녹화 형식: **Hybrid MP4*** (OBS 30.2 이상). 이러면 마크가 영상 파일 안에도 챕터로 들어갑니다. 바꾼 뒤에는 테스트 녹화로 **오디오 트랙 5개가 모두 따로 들어가는지** 꼭 확인하세요.

## 연동 (유튜브 아카이브 · 드라이브 · 치지직)

설정 창의 **연동** 아래 **Google 계정 · 유튜브 아카이브 · 드라이브 자동 업로드 · 치지직 연동** 칸에서 켜요. 칸마다 왜 필요한지와 단계별 안내가 있고, 끝난 단계에는 ✓가 붙어요.

- **Google 로그인** (유튜브 + 드라이브 공용): 내 Google Cloud 프로젝트를 하나 만들어 클라이언트 ID와 보안 비밀번호를 넣고 로그인합니다. 프로젝트는 꼭 **게시(프로덕션)** 상태로 두세요 — 테스트 상태면 7일마다 로그인이 풀려요. (게시하려면 Google Auth Platform의 **Branding**에 앱 이름·이메일과 함께 **홈페이지 주소와 개인정보처리방침 주소**가 필요해요. 내 유튜브/치지직 채널 주소와 공개 Gist 같은 아무 공개 페이지면 됩니다.) **허용 화면이 두 번** 나와요 — 유튜브, 이어서 드라이브. Google이 두 권한을 한 번에 못 받게 해서 나눴어요.
  - 첫 번째(유튜브)는 **아카이브를 올릴 채널**을 고르세요. 브랜드 계정 채널도 돼요.
  - 두 번째(드라이브)는 **녹화를 올릴 폴더가 있는 계정**을 고르세요. 브랜드 계정에는 드라이브가 없어서, 보통 내 기본 계정이에요.
  - 로그인 정보는 방송 PC에만 저장되고 로그 파일에도 들어가지 않아요.
- **유튜브 아카이브 지키기**
  - Allmind가 **전용 스트림 키**를 하나 만들어요. 설정 창에 한 번 보여 주는 주소와 키를 OBS Multi-RTMP의 유튜브 대상에 넣어 주세요(한 번만).
  - 방송마다 **비공개 · 자동 시작 · 자동 종료** 방송을 미리 만들어 두기 때문에, 지난 방송 결과 화면 때문에 유튜브가 시작되지 않는 문제가 생기지 않아요.
  - 방송 중에는 1분마다 확인해요. 공개/일부 공개로 바뀌면 **바로 비공개로 되돌리고**, 방송을 켰는데 유튜브가 시작되지 않으면 대시보드(폰 포함)에 빨간 알림을 띄워요.
  - 유튜브 제목은 `{date} - {title}` 형식(설정에서 바꿀 수 있어요). **방송 준비**에서 직접 적을 수도 있어요.
  - 다른 채널로 다시 로그인하면 예전 키는 그 채널 것이라 쓸 수 없어요. Allmind가 알려 주면 **스트림 키 만들기**를 다시 누르고 새 주소·키를 Multi-RTMP에 넣어 주세요.
- **드라이브 자동 업로드**
  - 녹화가 끝나면 영상과 `….markers.json`을 드라이브에 올려요. **드라이브 자동 업로드** 칸의 **올릴 폴더**에 내 드라이브 폴더 링크를 붙여 넣으면 그 폴더에, 비워 두면 Allmind가 만든 **Allmind 녹화** 폴더에 올라가요.
  - 이름은 `2026-10-26 - 방송 제목.mp4` — 제목은 그 녹화 동안 가장 오래 걸려 있던 치지직 제목이에요. 올리기 전에는 **방송 준비** 창의 업로드 목록에서 이름을 고칠 수 있어요. 원본 파일은 이름도 위치도 그대로예요.
  - **방송·녹화 중에는 올리지 않아요.** 끝나면 이어서 올리고, 인터넷이 끊기거나 Allmind를 다시 켜도 이어서 올려요. 속도 제한도 걸 수 있어요.
- **치지직 연동** (방송 준비): CHZZK Developers에 앱을 등록해 Client ID/Secret을 넣고 로그인하면, **방송 준비** 창에서 치지직 제목·카테고리·태그를 바꿀 수 있어요. 로그인은 30일 동안 안 쓰면 만료돼요.
- **방송 준비** (대시보드 위쪽 버튼): 치지직 제목·카테고리(검색)·태그를 적고 **적용**하면 치지직 · 유튜브 · 녹화 파일 이름에 한 번에 들어가고, 각각 성공했는지 표시돼요. 유튜브 제목과 녹화 파일 이름은 치지직 제목을 따라가고(`날짜 - 제목`), 직접 고치면 그대로 쓰여요(**↺ 자동**으로 되돌리기). 폰에서도 됩니다.

## 설정 옮기기 (다른 PC로)

다른 PC나 스튜디오에서 Allmind를 똑같이 쓰고 싶을 때 써요. 설정 창 **관리 → 설정 옮기기**에 있어요.

- **내보내기**: 비밀번호(8자 이상)를 정하면 바탕화면에 `Allmind 설정 날짜.allmind` 파일이 생겨요. 설정·OBS 비밀번호·소스 이름·폴더·치지직 채널·스트림덱 키, Google·치지직 연동 로그인, 유튜브 스트림 키 연결, 셋리스트 순서·볼륨, 룰렛 설정, 공중전 랭킹 등이 들어가요.
- 파일은 **그 비밀번호로 암호화**돼요(scrypt + AES-256-GCM). 비밀번호 없이는 아무도 (Allmind도) 열 수 없고, 비밀번호를 잊으면 복구할 수 없어요.
- **가져오기**: 다른 PC의 Allmind에서 파일과 비밀번호를 넣고 **열어 보기** → 어느 PC에서 언제 만든 파일인지, 무엇이 들어 있는지 확인 → **적용하고 다시 시작**. 지금 설정은 설정 폴더의 "가져오기 전 백업"에 남겨 둬요.
- 빠지는 것: 드라이브 업로드 대기열(그 PC의 파일이라서), 대시보드 패널 배치(브라우저마다 따로).
- 폴더 위치가 다른 PC라면 가져온 뒤 BGM·사운드보드 폴더를 확인하세요. 치지직 연동 로그인은 한 번 쓰면 바뀌는 방식이라, 두 PC에서 번갈아 쓰면 한쪽은 다시 로그인해야 할 수 있어요.

넓은 화면(PC, 가로로 둔 아이패드)에서는 OBS 독처럼 패널을 원하는 곳에 옮길 수 있어요.

- **옮기기**: 패널 제목 왼쪽의 **⠿**(또는 제목 줄의 빈 곳)를 잡고 끌어요.
  - 다른 패널의 **위/아래 절반**에 놓으면 그 패널 위나 아래로
  - 다른 패널의 **왼쪽/오른쪽 끝**에 놓으면 그 옆에 새 열로
  - 다른 패널의 **가운데**에 놓으면 탭으로 합쳐져요. 탭을 클릭하면 전환, 탭을 끌어서 다시 빼낼 수 있어요. 가려진 탭의 화면은 OBS에서 가져오지 않아서 부담이 없어요.

- 폰이나 세로 화면에서는 지금처럼 고정된 배치를 써요.

## 스트림덱 (BGM · 사운드보드)

**Allmind 스트림덱 플러그인**을 깔면 스트림덱 앱에 **Allmind** 묶음(BGM · 사운드보드 동작)이 생겨요. 키에는 지금 재생 중인 곡 제목, 재생/일시정지 상태, 재생 중인 사운드, 볼륨이 실시간으로 보여요. **메인 PC의 스트림덱도, 방송 PC의 스트림덱도** 같은 Allmind(방송 PC)를 씁니다. 마이크·장면 전환처럼 OBS 자체 스트림덱 기능으로 되는 것은 그쪽을 쓰세요.

**설치**
1. 방송 PC: Allmind 설정 창 → **스트림덱** 카드 → **플러그인 설치** → 스트림덱 앱이 묻는 창에서 설치.
2. 메인 PC: 같은 카드에 나온 주소(`http://<방송 PC 주소>:8080/streamdeck/Allmind.streamDeckPlugin`)를 메인 PC 브라우저에서 열고, 받은 파일을 더블클릭.
3. 메인 PC에서는 Allmind 키 하나를 골라 설정 아래 **연결 → Allmind 주소**에 `<방송 PC 주소>:8080` 을 넣고 **저장하고 다시 연결**. 그 PC의 Allmind 키 전부에 적용돼요. (방송 PC는 비워 두면 돼요.)

**키 만들기**: 스트림덱 앱 오른쪽 목록의 **Allmind** 에서 끌어다 놓고, 설정에서 동작을 고르세요.

| 동작 | 설정 | 키에 보이는 것 |
|---|---|---|
| BGM · 재생 / 일시정지 | — | ▶/⏸ (재생 중이면 초록), 지금 곡 제목 |
| BGM · 이 곡 재생 | 셋리스트에서 곡 선택 (**곡 찾기**로 거르기) | 곡 제목, 그 곡이 재생 중이면 초록. 재생 중에 누르면 일시정지 |
| BGM · 다음 곡 / 이전 곡 | — | ⏭ / ⏮ |
| BGM · 볼륨 올리기 / 내리기 | 한 번에 몇 dB (기본 3) | 지금 볼륨 |
| 사운드보드 · 사운드 재생 | 사운드보드 폴더에서 선택 | 사운드 이름, 재생 중이면 주황 ■ (한 번 더 누르면 정지) |
| 사운드보드 · 정지 / 볼륨 | — | 지금 볼륨 |

Allmind가 꺼져 있거나 닿지 않으면 키에 **연결 안 됨**이 뜨고, 다시 켜지면 저절로 붙어요. 플러그인은 키가 화면에 있을 때만 Allmind에 연결 하나를 열어 둬요 (OBS에 요청을 더 보내지 않아요). 방송 PC 주소가 바뀌지 않게 공유기에서 고정 IP를 잡아 두면 좋아요.

**플러그인 없이 (웹사이트 동작)**: 스트림덱의 **시스템 → 웹사이트** 동작에 주소를 붙여도 돼요(키에 상태는 안 보여요). 설정 창 스트림덱 카드의 **플러그인 없이…** 를 열고 주소를 **복사**해서 붙인 뒤 **백그라운드에서 접근(Access in background)** 을 체크하세요. ⭐ 마크(`/deck/mark`)는 지금은 이 방법으로만 돼요.

| 주소 | 동작 |
|---|---|
| `/deck/bgm-toggle` · `bgm-play` · `bgm-pause` | BGM 재생/일시정지 · 재생 · 일시정지 |
| `/deck/bgm-next` · `bgm-prev` | 다음 곡 · 이전 곡 |
| `/deck/bgm-vol-up` · `bgm-vol-down` | 볼륨 ±3 dB (`?step=5` 로 간격 변경) |
| `/deck/sb-play?name=박수` | 사운드보드 재생 (파일 이름 또는 제목, 겹치지 않는 일부만 써도 돼요) |
| `/deck/sb-stop` · `sb-vol-up` · `sb-vol-down` | 사운드보드 정지 · 볼륨 |
| `/deck/mark` | ⭐ 마크 (녹화 중일 때) |

주소 앞에는 `http://<방송 PC 주소>:8080` 이 붙어요(방송 PC의 스트림덱은 `http://localhost:8080`).

**비밀 키(선택)**: 설정 창에서 키를 정하면 모든 주소에 `?key=…` 가 붙고, 키가 없거나 틀린 요청은 거절됩니다. 같은 네트워크의 다른 사람·웹페이지가 BGM을 마음대로 건드리는 걸 막고 싶을 때 쓰세요. 키를 바꾸면 플러그인의 **연결 → 비밀 키**에도 같은 키를 넣고, 웹사이트 동작에 붙인 주소는 다시 복사해야 해요.

## Xylem (시청자 참여: 치즈 룰렛 · 공중전)

대시보드 오른쪽 위의 **🎮 Xylem** 버튼(또는 트레이 메뉴 "Xylem 열기")을 누르면 따로 창이 열려요. 주소는 `http://<방송 PC 주소>:8080/xylem` 이라 메인 PC·아이패드·폰에서도 열 수 있어요. 기능마다 왼쪽 메뉴에 칸이 하나씩 있고, 거기서 진행 상황을 보고 설정을 바꾸고 OBS에 넣을 주소를 복사해요. 대시보드 자리는 차지하지 않아요.

- **방송 중에도 고칠 수 있어요.** 룰렛·공중전 화면과 Xylem 창은 "팩"으로 따로 업데이트돼요. 위쪽에 **새 팩**이 보이면 **지금 적용** — Allmind를 다시 켜지 않고, OBS의 오버레이도 1~2초 안에 알아서 새로고침돼요. 문제가 있으면 **되돌리기**로 이전 팩(또는 내장 팩)으로 바로 돌아가요.
- 새 팩이 더 새로운 Allmind를 필요로 하면 "Allmind 업데이트 필요"라고 나오고 적용되지 않아요 (방송이 끝난 뒤 Allmind를 업데이트하세요).

### 치즈 룰렛

OBS에 브라우저 소스 `http://localhost:8080/roulette` (800×900 추천, 배경 투명). 효과음을 방송에 넣으려면 그 소스의 "OBS를 통해 오디오 제어"를 켜세요.

- **1회 가격**마다 1번씩 돌아가요 (1,000 치즈면 3,000 치즈 후원 → 3회). 한 번에 최대 횟수, 어떤 후원(채팅·영상·미션)으로 돌릴지 정할 수 있어요.
- 항목과 **가중치**(비율), 색을 Xylem 창에서 바꾸고 저장해요. 확률(%)이 바로 보여요.
- 결과는 Allmind가 정해서 기록하고, 화면은 그 결과로 돌아가는 모습만 보여줘요. 화면에 나오기 전에 OBS나 Allmind가 다시 켜져도 같은 결과로 이어서 보여줘요.
- 기록에서 벌칙 등을 했으면 **완료**에 체크. **테스트 1회/3회**로 미리 돌려볼 수 있어요 (기록에 "테스트"로 남아요).
- **등급**: 항목마다 자동 · 일반 · ✦ 희귀 · ★ 전설. 자동은 확률로 정해요 (5% 이하 전설, 15% 이하 희귀). 희귀는 천천히 멈추고 금빛으로 빛나요. 전설은 더 길게 돌다가 화면이 번쩍하고 꽃가루가 날려요. 룰렛 칸에도 희귀·전설 칸은 테두리가 반짝여요.
- **빠르게 돌리기**: 후원 1번에 정한 횟수(기본 3회) 이상이면 짧게 연달아 돌리고, 마지막에 **결과 요약**(꽝 ×4, 애교 ×1 …)을 보여줘요. 0이면 꺼져요.
- **🎲 무료 룰렛**: 후원 없이 방송인이 Xylem 창에서 돌리는 룰렛 (다음 게임 정하기, 벌칙 정하기 등). 여러 개 만들 수 있고, 같은 OBS 룰렛 화면에 나와요. 결과는 기록에 🎲로 남아요.

### 공중전 (대기·휴식 화면 미니게임)

OBS에 **브라우저 소스**를 추가하고 주소 `http://localhost:8080/dogfight`, 크기 **1920×1080** (배경 투명). 화면에 명령어 목록이 나와요. Xylem 창의 공중전 칸에서 주소 옵션을 골라 복사하고, 지금 시작·다음 판 보스전·랭킹 초기화를 할 수 있어요.

- 시청자: `!출격` 참전 · `!미사일` · `!플레어` · `!회피` (코브라 기동, 보스 빔도 피함) · `!특수` (무작위 특수무기: QAAM·4AAM·HPAA·ADMM·EML·TLS) · `!귀환`
- 방송인·매니저: `!시작` 바로 시작 · `!보스` 다음 라운드를 **보스전**으로 (모두 함께 공중요새 BASTION과 싸워요. 참가 인원에 맞춰 체력과 화력이 정해져요)
- **자동 조종 성향** (명령 사이에 내 기체가 어떻게 날지): `!공격형` 미사일 자주·플레어 적게 · `!회피형` 쫓기면 구름이나 태양 쪽으로 도망 · `!호위형` 팀원을 쫓는 적을 노림 (개인전에서는 나를 친 적에게 반격) · `!기본형`. 성향끼리 승률이 비슷하도록 맞춰 뒀어요.
- **날씨**: 라운드마다 **구름**과 **태양**이 생겨요. 구름 속의 기체는 미사일이 조준하지 못하고, 쫓던 미사일도 놓쳐요. 태양 쪽으로 곧장 도망치면 미사일이 햇빛에 눈이 멀어 놓칠 수 있어요. `?weather=0`이면 꺼져요.
- **팀전**: Xylem 창의 공중전 칸 → **모드**에서 팀전을 고르고 팀 수(2~4)와 팀 이름·색을 정해 저장. 다음 라운드부터 적용돼요. 시청자는 `!팀 1` · `!팀 2` … 또는 `!팀 이름`으로 팀을 고르고(`!출격`은 사람이 적은 팀으로), 대기 중에는 바꿀 수도 있어요. 팀마다 기체 수가 같도록 AI가 채우고, 팀전에서는 모든 기체가 같은 자동 조종을 써서 공평해요(시작 위치도 매번 섞여요). 마지막까지 남은 팀이 이기고, 시간이 다 되면 남은 기체·체력이 많은 팀이 이겨요. 결과는 Xylem 창의 **최근 팀전 결과**에 남아요 — 무언가를 정할 때 동전 던지기 대신 쓰세요.
- 후원은 게임에 영향을 주지 않아요.
- 주소 옵션: `?lobby=25` 대기 시간 · `?fighters=4` AI 포함 최소 기체 수 · `?boss=5` 5라운드마다 자동 보스전 · `?board=0` 랭킹 숨기기 · `?help=0` 명령어 목록 숨기기 · `?weather=0` 구름·태양 끄기 · `?demo=1` 가짜 시청자로 미리보기 (`&team=3` 팀전 미리보기)

## 단축키

기본으로 **꺼져 있어요.** 쓰려면 방송 PC 설정 창 → **관리 → 기타** → **대시보드 키보드 단축키**를 켜세요. 글자를 입력하는 칸에서는 켜져 있어도 동작하지 않아요.

| 키 | 동작 |
|---|---|
| `Space` | BGM 재생/일시정지 |
| `N` | 다음 곡 |
| `S` | 광고 스킵 |
| `F` | 영도 전체 화면 |
| `M` | ⭐ 마크 (녹화 중일 때) |
| `1`~`9`, `0` | 사운드보드 1~10번 재생 |

## 문제 해결

| 증상 | 해결 |
|---|---|
| OBS: "실행 중 (클릭 전달 꺼짐)" | OBS가 Allmind 밖에서 켜졌습니다. 방송 중이 아니라면 OBS를 닫고 **OBS 시작**. |
| OBS 연결 빨간색 | OBS의 WebSocket 서버가 꺼져 있거나 설정의 비밀번호가 틀렸습니다. |
| "OBS를 찾을 수 없음" | 설정 창 **OBS 연결 → OBS 위치**에 OBS 폴더(또는 `obs64.exe`)를 지정. |
| 메인 PC에서 응답 없음 | Windows 방화벽 차단입니다. Allmind의 **방화벽 허용**을 누르고 관리자 권한을 승인. |
| 메인 PC에서 주소가 안 열림 | 두 PC가 같은 네트워크인지 확인하고, 표시된 다른 주소로 시도. |
| 리모콘 창이 로그인을 요구 | 메인 PC Chrome에서 네이버/치지직에 한 번 로그인. 팝업이 막히면 대시보드 주소의 팝업을 허용. |
| 치지직 빨간색 / 채팅 없음 | 채널 주소 확인. 채팅·시청자 수는 치지직 웹 내부 엔드포인트를 쓰므로(비공식) 치지직 업데이트로 깨질 수 있습니다. 위플챗 탭은 그대로 동작합니다. |
| 위플챗 패널이 비어 있음 | 패널의 **⇄** 버튼으로 OBS 화면 방식으로 전환. |
| 유튜브 아카이브가 다른 채널에 올라감 / "스트림 키가 지금 로그인한 채널에 없어요" | Google 로그인을 다시 하고 첫 화면(유튜브)에서 아카이브 채널을 고른 뒤 **스트림 키 만들기** → 새 주소·키를 OBS Multi-RTMP에. |
| 드라이브: "Google 로그인을 한 번 더 해 주세요" | 올릴 폴더를 정했는데 예전 로그인이라 권한이 부족해요. **Google 로그인**을 다시 하세요. |
| Xylem 오버레이가 이상함 | Xylem 창 위쪽의 **되돌리기**로 이전 팩(또는 내장 팩)으로. |
| 그 밖의 문제 | 설정 창의 **로그 보내기**로 만든 zip을 보내 주세요. 직접 보려면 **설정 폴더 열기** → `data\allmind.log`. |

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install
sh tools/dev/up.sh     # 가짜 OBS + 가짜 치지직으로 실행 → http://127.0.0.1:8080
sh tools/dev/down.sh   # 끄기
sh tools/build-all.sh  # exe 빌드 (처음엔 빌드 도구를 자동으로 받아요)
```

자세한 빌드·릴리스 방법은 [docs/BUILDING.md](docs/BUILDING.md), 코드 구조와 작업 규칙은 [CLAUDE.md](CLAUDE.md)에 있어요.

Xylem 팩만 고칠 때(방송 중 패치): `public/xylem/`을 고치고 `node tools/xylem-pack.mjs --bump`로 팩 버전과 파일 해시를 올린 뒤 `main`에 푸시하면 돼요. Allmind 버전을 올리지 않으니 exe 릴리스는 생기지 않고, 앱의 Xylem 창에 **새 팩**이 떠요.

```
src/            서버 (OBS·치지직 연결, BGM, 사운드보드, 영도/방송 화면 미러링, 마크,
                유튜브·드라이브·치지직 연동, Xylem 팩·룰렛·공중전, 스트림덱, 설정 옮기기, 업데이트)
public/         대시보드(index.html, app.js, style.css, dock.js), 설정 창(launcher.*), /mark 페이지
public/xylem/   Xylem 팩: Xylem 창, 오버레이(roulette.html, dogfight.html), 패널, manifest.json
streamdeck/     스트림덱 플러그인 소스 (빌드: node tools/build-streamdeck.mjs → public/streamdeck/)
tools/          mock OBS·치지직·Google, exe/런처 빌드, xylem-pack.mjs, 개발용 스크립트(tools/dev)
docs/           빌드 방법, 기능 설계(plans/), 릴리스 노트(release-notes/)
build/          아이콘
```
