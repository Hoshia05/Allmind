# Arkbird

2PC 방송 환경을 위한 통합 대시보드입니다. **방송 PC**에서 `Arkbird.exe` 하나만 실행하면, 메인 PC·아이패드·폰에서는 브라우저로 주소만 열어 쓰면 됩니다. OBS(obs-websocket)와 치지직을 연결해 방송 중 필요한 것들을 한 화면에 모았습니다.

![Arkbird 화면 (시뮬레이션)](docs/screenshot.png)
<sub>OBS·치지직 목업 데이터로 만든 시뮬레이션 화면입니다.</sub>

## 다운로드

**[➡ 최신 버전 받기 (Releases)](../../releases/latest)** — `Arkbird-x.y.z.exe` 파일 하나만 받으면 됩니다. 설치도, Node.js도 필요 없습니다. (Windows 10/11, 64비트)

처음 한 번만 받으면 됩니다. 이후 새 버전은 앱 안의 [업데이트](#업데이트) 기능으로 설치해요. 예전 버전이 필요하면 [Releases](../../releases) 목록에서 받을 수 있습니다.

처음 실행하면 Windows가 *"Windows의 PC 보호"* 창을 띄울 수 있습니다. 코드 서명이 없는 프로그램이라 그렇습니다. **추가 정보 → 실행**을 누르세요.

## 기능

- **방송 화면 / 영도 탭**: OBS가 그리는 화면(방송 화면 또는 영도)을 그대로 보여 줍니다. 영도는 클릭·마우스 이동·스크롤 전달과 **광고 스킵**(수동/자동)을 지원하고, 영도가 재생되면 자동으로 영도 탭으로 넘어갑니다(**자동 전환** 스위치로 끌 수 있어요). 영도가 멈췄으면 **↻**로 브라우저 소스를 새로고침하고, **⤢**(또는 `F`)로 전체 화면을 쓸 수 있어요. 화질은 가볍게(30fps)/부드럽게/균형/고화질(최대 60fps)/무손실(PNG) 중 선택.
- **BGM 셋리스트**: 음악 폴더를 OBS로 재생합니다. 순서·셔플·한 곡 반복, 곡 순서 변경, 검색, 재생 위치 이동, 볼륨 조절을 지원하고, 폴더에 곡을 넣으면 **↻**로 다시 읽을 수 있어요. 음악 파일에 들어 있는 앨범 커버는 자동으로 빼고 재생해서(원본 파일은 그대로) 화면에 그림이 뜨거나 OBS 오디오 지연이 쌓이지 않습니다.
- **사운드보드**: 효과음 폴더의 파일마다 버튼이 생겨요. 누르면 바로 재생, 재생 중인 버튼을 다시 누르면 정지. 키보드 `1`~`9`, `0`으로 처음 10개를 재생할 수 있고, 폴더에 파일을 넣으면 자동으로 추가돼요.
- **영도 자동 일시정지**: 영도 소리가 나면 BGM을 멈추거나 볼륨을 낮췄다가 끝나면 되돌립니다. 첫 알림 소리부터 영상이 끝날 때까지 끊김 없이 유지됩니다(**첫 알림 후 유지** 슬라이더). 설정은 음악 패널의 **자동정지** 탭에 있어요.
- **채팅 · 후원 · 위플챗**: 치지직 채팅(이모티콘, 후원/영도/구독 강조), 이번 방송의 후원·영도·미션·구독 목록(읽음 표시와 **모두 읽음**, 재시작해도 유지), 위플챗 패널(패널 크기에 맞게 늘어납니다).
- **알림 화면**: 도네 알림 소스를 방송에 나가는 모습 그대로 확인.
- **방송 상태**: LIVE/OFFLINE, 시청자 수와 추이, 최고 시청자, 방송 시간, 제목, 비트레이트·드롭 프레임·인코딩/렌더 지연.
- **스튜디오 조작**: OBS 장면 전환 버튼, 마이크 음소거와 레벨 미터, ■ 정지 / 넘기기 / 알림 정지 (치지직 리모콘 버튼).
- **터치 기기 대응**: 아이패드·폰(Z 폴드 등)에서도 쓸 수 있게 세로 화면 레이아웃과 하단 탭(채팅·음악·알림 화면)을 지원합니다. 아래 **이 기기 설정**도 참고하세요.
- **⭐ 마크**: 방송 중 웃긴 순간에 버튼 하나로 녹화 파일에 표시. 나중에 유튜브 편집할 때(VOD Scout) 그 순간들이 하이라이트 후보가 됩니다. 폰·아이패드·단축키로도 누를 수 있어요.
- **OBS 부하 보호**: OBS가 프레임을 놓치기 시작하면 미러링 fps를 자동으로 낮춰 방송에 영향을 주지 않습니다.
- **바로가기 링크**: 상단 오른쪽에 **치지직 스튜디오 · 채팅 팝업 · 내 방송**이 채널 주소로 자동 만들어집니다. **채팅 팝업**은 대시보드 옆에 좁은 창으로 열려요. 링크를 더 넣으려면 [고급 설정](#고급-설정-configjson)의 `links`를 쓰세요.
- **이 기기 설정 (⚙)**: 상단의 ⚙ 버튼에서 기기(브라우저)마다 따로 저장되는 설정을 바꿉니다.
  - **데이터 절약**: 화면 미러링을 최대 15fps로 제한. 폰에서는 처음부터 켜져 있어요.
  - **화면 꺼짐 방지**, **버튼 진동**(진동을 지원하는 기기만)
  - **채팅 글자 크기**: 가− / 가+ / 100%
  - **치지직 리모콘 열기**, **레이아웃 초기화**
- **트레이 아이콘 · 설정 창**: 방송 PC 작업표시줄 트레이의 Arkbird 아이콘을 누르면 설정 창이 열리고, 오른쪽 클릭 메뉴에서 **Arkbird 열기 / 대시보드 열기 (이 PC) / 종료**를 고를 수 있어요. Arkbird를 한 번 더 실행하면 새로 켜지지 않고 켜져 있는 것의 설정 창이 열립니다. 설정 창은 OBS 비밀번호가 들어 있어서 **방송 PC에서만** 열려요(메인 PC·폰에서는 막혀 있습니다).
- **자동 업데이트 알림**: 새 버전이 나오면 알려 주고, 버튼 한 번으로 설치합니다. ([업데이트](#업데이트) 참고)

## 설치 (방송 PC, 처음 한 번)

1. `Arkbird-x.y.z.exe`를 아무 폴더에 두고 실행합니다. 설정은 `%APPDATA%\Arkbird`에 저장되어 버전을 바꿔도 유지됩니다.
   - **업데이트**: 새 exe를 받아 실행하면 끝입니다. 처음 실행 시 이전 버전의 설정과 셋리스트를 자동으로 가져옵니다.
   - 방화벽 창이 뜨면 **개인 네트워크**를 허용하세요(메인 PC에서 접속하려면 필요).
2. 창이 열리면 **설정**을 채웁니다.
   - **WebSocket 비밀번호**: OBS → *도구 → WebSocket 서버 설정*에서 서버를 켜고 *연결 정보 표시*의 비밀번호를 복사.
   - **OBS 소스 이름**: 영도·위플챗 소스를 목록에서 선택(마이크 소스는 비워 두면 OBS의 기본 마이크).
   - **음악 폴더**: **찾아보기**로 BGM 폴더 선택.
   - **사운드보드 폴더** (선택): 짧은 효과음 파일이 든 폴더.
   - **치지직 채널 주소**: 채널 링크 붙여넣기.
   - 그 밖에 **OBS 위치**(비워 두면 자동으로 찾아요), **Arkbird를 켤 때 OBS도 같이 켜기**, **Windows 시작 시 자동 실행**, 서버 **포트**(기본 8080, 보통 그대로)가 있어요.
   - **저장하고 다시 시작**.
3. OBS를 닫은 상태에서 **OBS 시작**을 누릅니다. 클릭 전달·광고 스킵을 쓰려면 OBS를 Arkbird로 켜야 합니다. 이후로는 자동입니다.
4. 대시보드에서 **현재 장면에 만들기**로 BGM 소스를 만들고, OBS에서
   - `BGM Player`를 BGM 트랙에 지정(*편집 → 고급 오디오 속성*)
   - 모든 장면에 추가(**+ → 미디어 소스 → 기존 항목 추가**). OBS는 활성 장면의 오디오만 재생합니다.
5. (선택) **■ 정지 / 넘기기 / 알림 정지**: OBS **독 → 사용자 지정 브라우저 독…**에 Arkbird에 표시된 리모콘 주소를 추가하고, 그 독에서 네이버에 로그인한 뒤 독을 열어 둡니다.

사운드보드를 쓴다면 대시보드의 사운드보드 칸에서 **만들기**를 누르세요. `Soundboard` 미디어 소스가 BGM 소스가 있는 장면마다 추가되고, 오디오 트랙·모니터링 설정도 BGM과 똑같이 맞춰져요.

**Windows 시작 시 자동 실행**을 켜면 로그인할 때 트레이에서 조용히 시작합니다.

### 업데이트

새 버전이 나오면 방송 PC의 설정 창 **업데이트** 칸과 대시보드 위쪽에 알림이 떠요(6시간마다 GitHub를 확인합니다). 설정 창에서 **지금 업데이트**를 누르면 새 exe를 받아서 검증한 뒤 스스로 교체하고 다시 시작해요. 설정은 그대로 유지됩니다.

- 자동으로 설치하지 않아요. 직접 눌러야만 설치됩니다.
- **방송 중이거나 녹화 중에는 설치할 수 없어요.** 끝난 뒤에 눌러 주세요.
- 확인 자체를 끄려면 설정 파일의 `update.check`를 `false`로 바꾸세요.

## 고급 설정 (config.json)

대부분은 설정 창과 대시보드에서 바꿀 수 있고, 아래는 파일을 직접 고쳐야 하는 것들입니다. 설정 창의 **설정 폴더 열기**로 폴더를 열고 `config.json`을 고친 뒤 Arkbird를 다시 시작하세요. (파일에는 바꾼 항목만 있으면 되고, 나머지는 기본값이 쓰입니다.)

| 항목 | 설명 |
|---|---|
| `server.port` / `server.host` | 접속 포트(기본 `8080`)와 열어 줄 주소(기본 `0.0.0.0` = 같은 네트워크 전체). |
| `app.openWindowOnStart` | 시작할 때 설정 창을 띄울지(기본 `true`). Windows 시작 시 자동 실행으로 켜질 때는 원래 창을 띄우지 않아요. |
| `app.startObs` | Arkbird를 켤 때 OBS도 같이 켜기 (설정 창의 같은 이름 항목). |
| `update.check` | `false`면 새 버전 확인을 끕니다. |
| `links` | 상단 링크 추가: `[{ "name": "내 링크", "url": "https://…" }]`. `"popup": true`를 넣으면 옆 창으로 열려요. |
| `chzzk.pollSeconds` / `chzzk.chatHistory` | 방송 상태 확인 간격(초, 최소 5)과 보관하는 채팅 수(기본 300). |
| `bgm.extensions` / `bgm.defaultVolumeDb` | 음악으로 인식할 확장자와 처음 볼륨(기본 -20 dB). |
| `soundboard.volumeDb` | 사운드보드 처음 볼륨(기본 -10 dB). 한 번 조절한 뒤에는 저장된 값이 쓰여요. |
| `autoPause.*` | 영도 자동 일시정지: `mode`(`pause` 멈춤 / `duck` 볼륨 낮춤), `thresholdDb`(감지 기준), `triggerMs`, `resumeAfterMs`(재개 대기), `introHoldMs`(첫 알림 후 유지), `duckDb`. 대부분 음악 패널의 **자동정지** 탭에서도 바꿀 수 있어요. |
| `interact.debugPort` | Arkbird가 OBS 브라우저 소스에 접속하는 디버깅 포트(기본 `9222`). Arkbird가 켜는 OBS는 항상 `9222`를 쓰니, OBS를 직접 다른 포트로 켜는 경우가 아니면 바꾸지 마세요. |
| `interact.autoSkipAds` / `interact.skipSelectors` | 광고 자동 스킵 기본값과, 스킵 버튼을 찾는 선택자 목록. 유튜브 화면이 바뀌어 스킵이 안 되면 여기에 선택자를 추가하세요. |
| `viewer.chatFps` | 위플챗 화면 미러링 fps(기본 6). |

## 메인 PC · 아이패드 · 폰에서 쓰기

1. 방송 PC의 Arkbird에서 **메인 PC에서 열기** 아래 주소(예: `http://192.168.0.10:8080`)를 확인합니다. 같은 네트워크여야 합니다.
2. 메인 PC Chrome에서 주소를 연 뒤 **⋮ → 저장 및 공유 → 바로가기 만들기… → 창으로 열기**를 하면 바탕화면 아이콘으로 앱처럼 열립니다.
3. 아이패드/폰은 Safari·Chrome으로 주소를 열고 **홈 화면에 추가**하면 전체 화면 앱처럼 쓸 수 있습니다.

## ⭐ 마크 (유튜브 편집용)

OBS가 **녹화 중**일 때 상단 바에 노란 **★ 마크** 버튼이 나타납니다. 웃긴 순간에 누르기만 하면 됩니다. 창이 뜨지 않으니 방송을 방해하지 않아요.

- **누르는 방법**
  - 대시보드의 **★ 마크** 버튼, 또는 키보드 `M`
  - 폰·아이패드: `http://<방송 PC 주소>:8080/mark` 를 열면 큰 버튼 하나짜리 페이지가 나옵니다. 홈 화면에 추가해 두면 편해요.
  - 단축키(메인 PC): `POST http://<방송 PC 주소>:8080/api/mark` 요청 하나면 됩니다. 메모를 같이 보내려면 `{"label":"메모"}`.
    AutoHotkey v2 예시 (Ctrl+Alt+M):
    ```ahk
    ^!m:: {
      req := ComObject("WinHttp.WinHttpRequest.5.1")
      req.Open("POST", "http://192.168.0.10:8080/api/mark", false)
      req.Send()
    }
    ```
- **메모**: **▾** 버튼(또는 /mark 페이지)의 목록에서 각 마크에 메모를 적을 수 있어요. 녹화가 끝난 뒤에도 됩니다.
- **저장**: 마크는 누를 때마다 바로 저장됩니다. 녹화가 끝나면 영상 옆에 **`<영상 이름>.markers.json`** 파일이 생겨요. 마크가 없는 녹화는 파일을 만들지 않습니다.
- **업로드**: 이 파일을 영상과 **같은 구글 드라이브 폴더**에 올려 주세요. 영상 이름을 바꿔도 괜찮아요(VOD Scout가 길이로 찾아냅니다).

**추천 OBS 설정**: *설정 → 출력 → 녹화 → 녹화 형식: **Hybrid MP4*** (OBS 30.2 이상). 이러면 마크가 영상 파일 안에도 챕터로 들어갑니다. 바꾼 뒤에는 테스트 녹화로 **오디오 트랙 5개가 모두 따로 들어가는지** 꼭 확인하세요.

## 패널 배치 바꾸기

넓은 화면(PC, 가로로 둔 아이패드)에서는 OBS 독처럼 패널을 원하는 곳에 옮길 수 있어요.

- **옮기기**: 패널 제목 왼쪽의 **⠿**(또는 제목 줄의 빈 곳)를 잡고 끌어요.
  - 다른 패널의 **위/아래 절반**에 놓으면 그 패널 위나 아래로
  - 다른 패널의 **왼쪽/오른쪽 끝**에 놓으면 그 옆에 새 열로
  - 다른 패널의 **가운데**에 놓으면 탭으로 합쳐져요. 탭을 클릭하면 전환, 탭을 끌어서 다시 빼낼 수 있어요. 가려진 탭의 화면은 OBS에서 가져오지 않아서 부담이 없어요.
- **크기**: 패널 사이 틈을 끌어서 조절, 더블클릭하면 균등하게.
- 배치는 기기(브라우저)마다 따로 저장돼요. 처음 상태로 되돌리려면 **⚙ → 레이아웃 초기화**.
- 폰이나 세로 화면에서는 지금처럼 고정된 배치를 써요.

## 단축키

| 키 | 동작 |
|---|---|
| `Space` | BGM 재생/일시정지 |
| `N` | 다음 곡 |
| `S` | 광고 스킵 |

## 문제 해결

| 증상 | 해결 |
|---|---|
| OBS: "실행 중 (클릭 전달 꺼짐)" | OBS가 Arkbird 밖에서 켜졌습니다. 방송 중이 아니라면 OBS를 닫고 **OBS 시작**. |
| OBS 연결 빨간색 | OBS의 WebSocket 서버가 꺼져 있거나 설정의 비밀번호가 틀렸습니다. |
| "OBS를 찾을 수 없음" | 설정 → OBS 위치에 OBS 폴더(또는 `obs64.exe`)를 지정. |
| 메인 PC에서 응답 없음 | Windows 방화벽 차단입니다. Arkbird의 **방화벽 허용**을 누르고 관리자 권한을 승인. |
| 메인 PC에서 주소가 안 열림 | 두 PC가 같은 네트워크인지 확인하고, 표시된 다른 주소로 시도. |
| 리모콘 창이 로그인을 요구 | 메인 PC Chrome에서 네이버/치지직에 한 번 로그인. 팝업이 막히면 대시보드 주소의 팝업을 허용. |
| 치지직 빨간색 / 채팅 없음 | 채널 주소 확인. 채팅·시청자 수는 치지직 웹 내부 엔드포인트를 쓰므로(비공식) 치지직 업데이트로 깨질 수 있습니다. 위플챗 탭은 그대로 동작합니다. |
| 위플챗 패널이 비어 있음 | 패널의 **⇄** 버튼으로 OBS 화면 방식으로 전환. |
| 그 밖의 문제 | **설정 폴더 열기** → `data\arkbird.log` 확인. |

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install
sh tools/dev/up.sh     # 가짜 OBS + 가짜 치지직으로 실행 → http://127.0.0.1:8080
sh tools/dev/down.sh   # 끄기
sh tools/build-all.sh  # exe 빌드 (처음엔 빌드 도구를 자동으로 받아요)
```

자세한 빌드·릴리스 방법은 [docs/BUILDING.md](docs/BUILDING.md), 코드 구조와 작업 규칙은 [CLAUDE.md](CLAUDE.md)에 있어요.

```
src/       서버 (OBS·치지직 연결, BGM, 사운드보드, 영도/방송 화면 미러링, 마크)
public/    대시보드 웹 화면 (index.html, app.js, style.css, dock.js)
tools/     mock OBS, exe/런처 빌드, 개발용 스크립트(tools/dev)
build/     아이콘
```
