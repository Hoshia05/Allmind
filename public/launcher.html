          GOOGLE (유튜브 아카이브 · 드라이브 업로드)
          
          
          

            
            
          

          

            처음 한 번: Google 클라우드 프로젝트 만들기 (10분)
            
    
              
  1. Google Cloud 콘솔에서 새 프로젝트를 만들어요 (이름은 아무거나, 예: Allmind).
    2. 
              
  2. API 및 서비스 → 라이브러리에서 YouTube Data API v3와 Google Drive API를 각각 사용으로.
    3. 
              
  3. OAuth 동의 화면: 사용자 유형 외부, 앱 이름·이메일만 채우고 저장. 테스트 사용자에 내 구글 계정을 추가.
    4. 
              
  4. 같은 화면에서 앱 게시(프로덕션으로 푸시)를 눌러요. 테스트 상태로 두면 7일마다 다시 로그인해야 해요. 검증은 안 받아도 돼요.
    5. 
              
  5. 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID, 유형 데스크톱 앱. 나온 클라이언트 ID와 보안 비밀번호를 위에 붙여 넣어요.
    6. 
              
  6. Google 로그인을 누르면 브라우저가 열려요. 허용 화면이 2번 나와요(먼저 유튜브, 이어서 드라이브) — Google이 한 번에 못 받게 해서 나눴어요. 둘 다 같은 계정으로 하세요. "Google에서 확인하지 않은 앱" 화면이 나오면 고급 → (앱 이름)(으)로 이동을 누르고, 유튜브·드라이브 권한을 허용해요. 방송하는 유튜브 채널의 계정으로 로그인하세요.
    7. 
            

          

        


        

          유튜브 아카이브
          
          공개로 바뀌면 바로 비공개로 되돌리고, 방송을 켰는데 유튜브가 시작되지 않으면 대시보드에 알려요.
          
          

            
            
          

          

            
OBS의 Multi-RTMP 유튜브 대상에 이 서버 주소와 키를 넣어 주세요 (한 번만). 키는 비밀번호처럼 다른 사람에게 보여 주지 마세요.

            

            

          

        


        

          드라이브 자동 업로드
          
          방송·녹화 중에는 올리지 않아요. 원본 파일은 그대로 두고, 드라이브의 Allmind 녹화 폴더에 올려요 (폴더는 드라이브에서 원하는 곳으로 옮겨도 돼요).
          
          
        


        

          치지직 연동 (방송 준비: 제목·카테고리·태그)
          
          
          
          

            
            
          

          

            처음 한 번: 치지직 개발자 앱 등록
            
    
              
  1. CHZZK Developers에 방송하는 네이버 계정으로 로그인해 애플리케이션을 등록해요.
    2. 
              
  2. 로그인 리디렉션 URL에 위 주소를 넣고, 권한(scope)은 방송 설정 조회, 방송 설정 변경, 유저 정보 조회를 골라요.
    3. 
              
  3. 받은 Client ID와 Client Secret을 위에 붙여 넣고 치지직 로그인.
    4. 
              
  4. 로그인은 30일 동안 쓰지 않으면 만료돼요. 방송할 때마다 쓰면 계속 이어져요.
    5.
