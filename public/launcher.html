      🎛️OBS 연결Allmind의 거의 모든 기능이 OBS를 통해 움직여요
      

        
Allmind는 OBS에 붙어서 BGM을 틀고, 영도·채팅 화면을 대시보드에 보여 주고, 마이크·장면·녹화 상태를 읽어요. OBS에 들어 있는 WebSocket 서버로 연결해요 (OBS 28 이상이면 따로 설치할 건 없어요).

        
쓰는 곳 BGM사운드보드영도 뷰어방송 화면마이크·장면⭐ 마크녹화 업로드

        
    
          
  1. OBS → 도구 → WebSocket 서버 설정에서 WebSocket 서버 사용을 체크해요.
    2. 
          
  2. 같은 창의 연결 정보 표시를 눌러 나온 비밀번호를 아래에 붙여 넣어요.
    3. 
          
  3. 저장하고 다시 시작 → 위 상태에 OBS 연결: 연결됨이 뜨면 끝.
    4. 
        

        
💡 OBS는 위의 OBS 시작 버튼(또는 아래 "같이 켜기")으로 켜세요. 그래야 영도 화면 클릭 전달·광고 스킵이 켜져요.

        

          
          
          
        

        

      

    


    

      💬치지직 채널채팅·시청자·후원을 읽어 와요 (로그인 없이)
      

        
내 채널 주소만 있으면 로그인 없이 채팅, 후원, 방송 상태를 읽을 수 있어요. 제목·카테고리를 바꾸는 건 아래 치지직 연동이 따로 필요해요.

        
쓰는 곳 채팅 패널시청자 수후원 목록치즈 룰렛공중전 명령어채팅 로그 (SkyEye)치지직 리모컨

        
    
          
  1. 치지직에서 내 채널 페이지를 열고 주소창의 주소를 그대로 복사해 아래에 붙여 넣어요.
    2. 
          
  2. 저장하고 다시 시작.
    3. 
        

        

          
          
          녹화하는 동안의 채팅을 영상과 같은 시간대로 ….markers.json 파일에 저장해요.
        

        

      

    


    

      🎵BGM · 사운드보드셋리스트 폴더와 효과음 폴더
      

        
BGM은 OBS의 미디어 소스 하나로 폴더의 노래를 차례로 틀어요. 영도가 나오면 저절로 멈췄다가 끝나면 다시 틀어요. 사운드보드는 짧은 효과음용 소스가 따로 있어요.

        
쓰는 곳 대시보드 BGM 패널사운드보드영도 자동 일시정지스트림덱

        
    
          
  1. 음악 폴더를 골라요 → 저장하고 다시 시작.
    2. 
          
  2. 대시보드 BGM 패널에서 소스 만들기를 눌러요 (이미 쓰는 미디어 소스가 있으면 아래에 그 이름을 넣어도 돼요).
    3. 
          
  3. (선택) 사운드보드 폴더를 고르고, 대시보드 사운드보드 패널에서 소스를 만들어요.
    4. 
        

        
💡 BGM·사운드보드 소스는 OBS에서 숨기지 마세요 — 숨긴 소스는 OBS가 소리를 꺼요. 안 보이게 하려면 그룹 크기를 0으로 줄이세요.

        

          
          
          
        

        

      

    


    

      🖼️화면 소스 (영도 · 위플챗 · 알림 · 마이크)대시보드에 보여 줄 OBS 소스 이름
      

        
대시보드는 이 OBS 소스들의 화면을 받아서 보여 줘요. 영도 화면은 대시보드에서 누르면 OBS 안의 영도 페이지에 그대로 클릭이 전달돼요 (광고 건너뛰기 등). 이름만 맞으면 OBS 쪽은 바꿀 게 없어요.

        
쓰는 곳 영도 뷰어위플챗 패널후원 탭 알림 화면마이크 상태

        
    
          
  1. 영도 브라우저 소스 이름을 골라요 (입력칸을 누르면 OBS 소스 목록이 나와요).
    2. 
          
  2. 위플챗 브라우저 소스 이름을 골라요.
    3. 
          
  3. (선택) 알림·마이크 → 저장하고 다시 시작.
    4. 
        

        

          
          
          
          
          
          

        

        

      

    


    

      🖥️메인 PC · 아이패드 · 폰에서 열기대시보드 주소와 방화벽
      

        
대시보드는 방송 PC가 아니라 메인 PC, 아이패드, 폰의 브라우저에서 쓰는 게 기본이에요. 같은 공유기(와이파이)에 있으면 아래 주소로 열려요. 방송 PC의 Windows 방화벽이 막고 있으면 한 번 허용해 줘야 해요.

        

          …
          
        

        

        

          
          
          
        

        
    
          
  1. 방화벽이 막고 있으면 방화벽 허용 (관리자 확인 창이 떠요).
    2. 
          
  2. 메인 PC 크롬에서 위 주소를 열어요.
    3. 
          
  3. (추천) 크롬 ⋮ → 저장 및 공유 → 바로가기 만들기… → 창으로 열기 체크 → 바탕화면 아이콘으로 탭 없는 창이 바로 열려요.
    4. 
        

        
💡 공유기에서 방송 PC의 IP를 고정해 두면 주소가 안 바뀌어요.

      🔑Google 계정유튜브 아카이브 · 드라이브 업로드에 필요해요
      

        
Allmind가 내 유튜브 채널에 비공개 방송을 만들고, 드라이브에 녹화를 올리려면 Google의 허락이 필요해요. Google은 개인이 만든 프로그램에게 내 Google Cloud 프로젝트를 하나 만들게 하고, 그 프로젝트의 클라이언트 ID로 로그인하게 해요. Google 비밀번호는 Allmind가 보지 않아요.

        
쓰는 곳 유튜브 아카이브드라이브 자동 업로드

        
  • Google…

        

          처음 한 번: Google Cloud 프로젝트 만들기 (10분)
          
    
            
  1. Google Cloud 콘솔에서 새 프로젝트를 만들어요 (이름은 아무거나, 예: Allmind).
    2. 
            
  2. API 및 서비스 → 라이브러리에서 YouTube Data API v3와 Google Drive API를 각각 사용으로.
    3. 
            
  3. Google 인증 플랫폼 → 브랜딩: 앱 이름·지원 이메일·홈페이지·개인정보처리방침 주소를 채워요 (내 채널 주소 같은 걸 넣어도 돼요). 대상은 외부.
    4. 
            
  4. 대상 → 앱 게시(프로덕션으로 푸시). 테스트 상태로 두면 7일마다 다시 로그인해야 해요. 검증은 안 받아도 돼요.
    5. 
            
  5. 클라이언트 → 클라이언트 만들기, 유형 데스크톱 앱. 나온 클라이언트 ID와 보안 비밀번호를 아래에 붙여 넣어요.
    6. 
          

        

        
    
          
  1. 위 안내대로 만든 클라이언트 ID와 보안 비밀번호를 붙여 넣어요.
    2. 
          
  2. Google 로그인 → 첫 번째 허용 화면: 아카이브를 올릴 유튜브 채널을 골라요 (브랜드 채널이어도 돼요).
    3. 
          
  3. 이어서 두 번째 허용 화면: 녹화를 올릴 드라이브가 있는 계정을 골라요.
    4. 
        

        
💡 "Google에서 확인하지 않은 앱"이 나오면 고급 → (앱 이름)(으)로 이동. 허용 화면이 두 번인 건 Google이 유튜브와 드라이브 권한을 한 번에 못 받게 해서예요.

        

          
          
        

        

          
          
        

      

    


    

      ▶️유튜브 아카이브방송마다 비공개 다시보기를 자동으로
      

        
OBS의 Multi-RTMP로 유튜브에도 같이 송출해서 비공개 다시보기를 남겨요. Allmind는 방송마다 비공개 방송을 미리 만들어 두고, 방송 중에 공개로 바뀌면 바로 되돌리고, 송출했는데 유튜브가 시작되지 않으면 대시보드에 알려 줘요. 방송이 끝나면 유튜브 방송도 Allmind가 끝내 둬요.

        
필요한 것 Google 계정 (유튜브) 쓰는 곳 아카이브방송 준비 (유튜브 제목)

        
  • 유튜브…

        
    
          
  1. Google 계정을 먼저 연결해요.
    2. 
          
  2. 아래 비공개 아카이브 준비를 켜고 저장해요.
    3. 
          
  3. 스트림 키 만들기를 눌러요.
    4. 
          
  4. OBS의 Multi-RTMP 유튜브 대상에 나온 서버 주소와 키를 넣어요 (예전 키 대신, 한 번만).
    5. 
        

        

          
          
        

        

          
          
          
        

        

          
OBS의 Multi-RTMP 유튜브 대상에 이 서버 주소와 키를 넣어 주세요 (한 번만). 키는 비밀번호처럼 다른 사람에게 보여 주지 마세요.

          

          

        

      

    


    

      ☁️드라이브 자동 업로드녹화가 끝나면 영상과 ⭐ 마크를 드라이브에
      

        
방송이 끝나면 녹화 파일과 ⭐ 마크·채팅 파일(….markers.json)을 내 드라이브 폴더에 올려서 편집자와 바로 나눌 수 있어요. 방송·녹화 중에는 올리지 않아서 방송에 영향이 없고, 끊기면 이어서 올려요. 원본 파일은 그대로 둬요.

        
필요한 것 Google 계정 (드라이브) 쓰는 곳 편집자 공유SkyEye

        
  • 드라이브…

        
    
          
  1. Google 계정을 먼저 연결해요 (두 번째 허용 화면이 드라이브예요).
    2. 
          
  2. 아래 자동 업로드를 켜요.
    3. 
          
  3. (선택) 드라이브에서 올릴 폴더를 열고, 주소창의 링크를 올릴 폴더에 붙여 넣고 저장해요. 비워 두면 "Allmind 녹화" 폴더를 만들어요.
    4. 
        

        

          
          
          

          
          
        

        

      

    


    

      📝치지직 연동 (방송 준비)제목·카테고리·태그를 대시보드에서 바꾸기
      

        
방송 제목·카테고리·태그를 바꾸는 건 치지직 공식 API로만 할 수 있어서, CHZZK Developers에 내 앱을 등록하고 로그인해야 해요. 채팅·후원을 읽는 데는 필요 없어요 (그건 치지직 채널만으로 돼요).

        
쓰는 곳 대시보드 방송 준비 (치지직 제목·카테고리·태그)

        
  • 치지직 연동…

        
    
          
  1. CHZZK Developers에 방송하는 네이버 계정으로 로그인해 애플리케이션을 등록해요. 로그인 리디렉션 URL에는 아래 주소를, 권한은 방송 설정 조회·방송 설정 변경·유저 정보 조회를 골라요.
    2. 
          
  2. 받은 Client ID와 Client Secret을 아래에 붙여 넣어요.
    3. 
          
  3. 치지직 로그인. 30일 동안 안 쓰면 로그인이 만료되지만, 방송할 때마다 쓰면 계속 이어져요.
    4. 
        

        

          
          
          
        

        

          
          
        

      

    


    

      ⏭️치지직 리모컨영도 넘기기 · 알림 정지 버튼
      

        
치지직 스튜디오의 리모컨 페이지를 OBS 안에 독으로 열어 두면, 대시보드의 넘기기·알림 정지 버튼이 그 페이지의 버튼을 대신 눌러요. 영도가 나올 때 BGM을 멈추는 데도 이 독의 신호를 같이 써요.

        
필요한 것 치지직 채널 쓰는 곳 넘기기알림 정지BGM 자동 일시정지

        
  • 리모컨 독확인 중…

        
    
          
  1. OBS 메뉴 → 독 → 사용자 지정 브라우저 독… → 이름 치지직 리모컨, URL에 아래 주소를 붙여 넣고 적용.
    2. 
          
  2. 새로 생긴 독에서 네이버 로그인 (OBS가 기억해요).
    3. 
          
  3. 독은 OBS 안 아무 곳에 두면 돼요. 닫지만 마세요.
    4. 
        

        
치지직 채널을 먼저 설정해 주세요
