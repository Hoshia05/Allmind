## 새 기능
- **✂ 파트 나누기**: 한 방송에서 주제가 바뀔 때, 녹화와 유튜브 아카이브를 그 자리에서 끊고 바로 새 파트를 시작해요. **방송 중에 몇 번이든** 나눌 수 있어요.
  - **LIVE** 버튼 → **✂ 파트 나누기**: 다음 파트 제목을 적고 두 번 누르면 나눠요.
  - **방송 준비**에 **적용하면서 ✂ 여기서 나누기** 체크가 생겼어요 (치지직 제목·카테고리도 같이 바뀌어요).
  - 유튜브: 다음 파트 방송을 먼저 만든 뒤 OBS가 파일을 끊고, 지난 파트는 끝내고 새 파트는 바로 시작해요 (비공개 설정 그대로).
  - 지난 파트는 자기 마크 파일과 함께 드라이브 업로드 목록에 들어가요 (업로드는 방송이 끝난 뒤). 새 파트의 마크·채팅 시간은 0부터 다시 세요.
  - OBS가 파일 나누기를 거절하면 이유를 알려 주고, **녹화를 껐다 켜서 나누기** 버튼이 나와요 (몇 초는 녹화가 비어요).
  - 방송만, 또는 녹화만 하는 중에도 있는 것만 나눠요.

## 알아 두세요
- 아직 가상 OBS·유튜브로만 시험했어요. 실제 OBS가 Hybrid MP4에서 나누기를 받아 주는지, 유튜브가 바뀌는 데 몇 초 걸리는지, 유튜브 채팅이 새 방송을 따라가는지는 처음 쓸 때 확인해 주세요.
