## 바뀐 점
- **방송 준비에서 치지직 제목·유튜브 제목·녹화 파일 이름을 따로 정할 수 있어요.**
  - 처음에는 유튜브 제목과 파일 이름이 치지직 제목을 따라가요(`2026-10-26 - 제목`). 그 칸을 직접 고치면 그때부터는 쓴 그대로 쓰여요.
  - **↺ 자동**을 누르면 다시 치지직 제목을 따라가요. 칸을 비워 두고 적용해도 자동이에요.
  - 직접 쓴 유튜브 제목은 준비해 둔 비공개 방송에 그대로 들어가고, 파일 이름은 그다음 녹화를 드라이브에 올릴 때 쓰여요. 둘 다 적용 후 12시간 동안 유지돼요.
