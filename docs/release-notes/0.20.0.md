## 바뀐 점
- **프로그램 이름이 Allmind로 바뀌었어요.** 화면·설정 창·트레이·exe 이름이 모두 Allmind입니다. (아이콘은 그대로예요.)
- 예전 Arkbird 설정은 처음 실행할 때 **자동으로 가져와요** (`%APPDATA%\Arkbird` → `%APPDATA%\Allmind`). 기존 방화벽 허용과 Windows 시작 프로그램 등록도 그대로 인식하고, 시작 프로그램은 새 이름으로 바꿔 줘요.
- 이전 Arkbird 앱 폴더(`%LOCALAPPDATA%\Arkbird`)는 새 버전이 시작된 뒤 자동으로 정리돼요.
- 로그 파일 이름은 `data\allmind.log`로 바뀌었어요.
- 릴리스에 `Arkbird-0.20.0.exe`도 같이 올라가 있어요. 예전 버전의 업데이트 기능이 새 버전을 찾을 수 있게 하는 **같은 파일**입니다.

## 업데이트 방법
Arkbird(또는 Allmind) 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
