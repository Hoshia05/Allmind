## 바뀐 점
- **🔒 다른 기기 PIN (선택, 기본 꺼짐)**: 설정 창 **다른 기기에서 열기 → PIN**. 켜면 메인 PC·아이패드·폰은 처음 한 번 PIN(숫자 4~8자리)을 넣어야 대시보드·Xylem·마크 페이지가 열려요. 한 번 넣은 기기는 기억해요 (오래 안 쓰면 400일 뒤에 다시 물어요).
  - **PIN 없이 그대로**: 방송 PC 자신, OBS 오버레이(룰렛·안내판·공중전·텍스트), 스트림덱, Google·치지직 로그인.
  - **스트림덱**: 메인 PC의 스트림덱은 PIN 대신 **비밀 키**로 연결돼요. PIN을 켤 때 비밀 키가 없으면 저절로 만들어서 보여 줘요 → 메인 PC 플러그인의 **연결 → 비밀 키**에 넣어 주세요. 방송 PC의 스트림덱은 비밀 키가 없어도 돼요.
  - **모든 기기 로그아웃**: 폰을 잃어버렸을 때 등. 열려 있던 화면도 바로 PIN 화면으로 바뀌어요.
  - PIN을 5번 틀리면 그 기기는 5분 동안 잠겨요.
  - AutoHotkey 등으로 `/api/mark`를 부르고 있었다면, PIN을 켠 뒤에는 `/deck/mark?key=<비밀 키>`를 쓰세요.
- 대시보드 연결이 끊겼을 때 영어로 나오던 표시를 한국어로 (**Allmind 연결 끊김 — 다시 연결하는 중**).

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
