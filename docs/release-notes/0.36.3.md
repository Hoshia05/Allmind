## 바뀐 점
- **유튜브에 '예정된 방송'이 여러 개 쌓이던 문제 고침**: Allmind가 준비해 둔 방송을 놓치면 새로 하나를 또 만들어서, 같은 키에 비공개 방송이 여러 개 대기하고 있었어요. 그러면 유튜브가 Allmind가 보고 있지 않은 방송을 시작해서 "아카이브가 안 들어가요" 경고가 잘못 뜨기도 했어요.
  - 이제 새로 만들기 전에 **대기 중인 방송을 다시 써요**.
  - Allmind가 만든(설명이 `[allmind]`로 시작하는) 대기 방송이 같은 키에 여러 개면 **하나만 남기고 지워요**. 방송한 적 없는 빈 예약이라 지워도 잃는 건 없어요. 직접 만든 방송이나 다른 키에 묶인 방송은 건드리지 않아요.
  - 방송 중에 유튜브가 Allmind의 다른 대기 방송을 시작했으면 **그 방송을 따라가요** (비공개도 확인).

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
