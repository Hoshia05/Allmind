## 바뀐 점
- **Xylem을 대시보드 안에서**: 위쪽 **🎮 Xylem** 버튼(폰은 아래 탭의 **🎮 Xylem**)을 누르면 새 탭이 아니라 대시보드 안에서 Xylem 화면으로 바뀌어요. 다시 누르면(**← 대시보드** / 폰은 채팅·음악·알림 화면 탭) 바로 돌아와요.
  - 한 번 열면 그대로 두었다가 보여 주기만 해서, 오가도 다시 불러오지 않고 보던 곳(예: 텍스트)에 그대로 있어요.
  - Xylem을 보는 동안에는 대시보드의 OBS 화면 미리보기를 멈추고, 대시보드를 보는 동안에는 Xylem이 쉬어요 — 방송 PC 부담은 늘지 않아요.
  - 따로 창으로 열고 싶으면 Ctrl+클릭, 또는 Xylem 화면 위쪽의 **↗**.
- 폰에서 Xylem 메뉴 이름이 한 글자씩 줄바꿈되던 것을 고쳤어요.
