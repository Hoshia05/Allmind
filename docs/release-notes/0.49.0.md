## 새 기능
- **🎮 어시스턴트가 Xylem도 조작해요**: API 토큰으로 연결한 어시스턴트가 이제 Xylem의 **텍스트 · 시청자 추첨 · 무료 룰렛 · VTS 던지기**도 쓸 수 있어요.
  - 텍스트는 200자까지, 지우거나 숨기면 바로 원래대로 돌아가요.
  - **어시스턴트가 연 추첨은 채팅에 공지를 올리지 않아요** (호시아 계정으로 채팅을 보내는 일은 어시스턴트에게 절대 맡기지 않아요).
  - Xylem → VTube Studio에서 **던지기를 꺼 두면 어시스턴트도 못 던져요**.
  - 방송 켜고 끄기, 채팅 보내기, 설정 같은 위험한 조작은 지금처럼 토큰으로도 못 해요.

## 바뀐 점
- Xylem을 Allmind 안에서 **따로 떨어진 부품(모듈)** 으로 옮겼어요. 쓰는 방법과 기능, 저장된 설정·룰렛·추첨 기록은 **그대로**예요.
- 대시보드의 🎮 Xylem 버튼, 폰 화면의 Xylem 탭, 트레이 메뉴의 **Xylem 열기**, 작업 표시줄의 Xylem 창 아이콘이 이제 Xylem이 켜져 있을 때만 나타나요. 평소처럼 쓰면 달라 보이는 건 없어요.
- 방송 리포트가 룰렛 부분 없이도 깨지지 않게 고쳤어요.

## 알아 두세요
- 업데이트한 뒤 **트레이 메뉴의 Xylem 열기**와 **Xylem 창의 작업 표시줄 아이콘**이 예전처럼 보이는지 한 번 확인해 주세요. 이 두 가지는 실제 Windows에서 아직 시험하지 못했어요.
- 나머지는 가상 OBS·가상 치지직·가상 VTS로 시험했어요.
- 스트림덱 플러그인은 바뀌지 않았어요 (0.48.0에서 1.2.0으로 다시 설치했다면 그대로 쓰면 돼요).

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
