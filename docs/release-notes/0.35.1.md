## 바뀐 점
- **VTube Studio 연결 고침**: VTube Studio에서 허용했는데도 "허용 기다리는 중"에 멈춰 있던 문제를 고쳤어요. 허용 창이 떠 있는 동안 다시 연결해도 기다리던 연결을 끊지 않고, 늦게 온 허용도 받아서 이어서 로그인해요.
- 주소를 비워 두면 이제 이 PC(127.0.0.1)로 연결하지 않고 **메인 PC 주소를 넣어 달라고** 알려 줘요.
- VTube Studio 연결 단계가 로그에 남아요 (로그 보내기로 확인 가능).
