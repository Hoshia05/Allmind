## 바뀐 점 (모션캡처 스튜디오 방송에서 배운 것)
- **방송 연결이 끊기면 알려 줘요**: 인터넷이 끊겨 OBS가 다시 연결하는 동안 대시보드에 빨간 경고가 뜨고, 다시 연결되면 몇 초 끊겼는지 알려 줘요. 방송 기록에도 남아요.
- **OBS 소리 지연 경고**: 소스가 잠깐 멈추면(예: 네트워크로 받는 NDI 소스) OBS가 소리를 늦춰서 맞추는데, OBS를 다시 켜기 전까지는 계속 늦게 나가요. 이제 300ms 이상 늦어지면 대시보드와 점검에 알려 줘요 (스튜디오 방송에서는 약 1초 늦게 나갔어요).
- **방송을 금방 다시 켜면 기록이 하나로**: 10분 안에 다시 시작하면 같은 방송 기록에 이어서 적어요 (끊긴 시간도 남겨요).
- **드라이브 업로드는 방송이 끝나고 5분 뒤에**: 방송을 다시 켜는 동안 업로드가 끼어들지 않게요.
- **이 PC에서 지우기**: 드라이브에 아직 안 올라간 녹화가 있으면 한 번 더 물어봐요.
- **로그 보강**: OBS 연결/끊김, OBS 비밀번호 거절, 유튜브 아카이브 경고가 로그에 남아요 (문제를 나중에 찾기 쉽게).
