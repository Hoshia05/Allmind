## 바뀐 점
- **로그 보내기 버튼**: 설정 창 맨 위의 **로그 보내기**를 누르면 Allmind 로그, OBS 최근 로그 3개, OBS 충돌 보고서, 간단한 정보(버전·연결 상태·설정)를 zip 하나로 **바탕화면**에 만들고 탐색기에서 보여 줘요. 문제가 생기면 이 파일 하나만 보내 주세요.
  - 비밀번호·토큰 같은 값은 들어가지 않아요.
- 설정 창 상단에 Allmind 이름이 다시 보이게 고쳤어요(좁은 창에서 아이콘만 보이던 문제).

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
