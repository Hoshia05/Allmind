## 바뀐 점
### 공중전
- **자동 조종 성향**: `!공격형` (미사일 자주·플레어 적게) · `!회피형` (쫓기면 구름이나 태양 쪽으로) · `!호위형` (팀원을 쫓는 적을 노림, 개인전에서는 반격) · `!기본형`. 성향끼리 승률이 비슷하게 맞춰져 있어요.
- **구름과 태양**: 라운드마다 바뀌어요. 구름 속의 기체는 미사일이 조준하지 못하고 쫓던 미사일도 놓쳐요. 태양 쪽으로 곧장 도망치면 미사일이 놓칠 수 있어요. 주소에 `?weather=0`이면 꺼져요.
- **팀전**: Xylem 창 → 공중전 → **모드**에서 팀 수(2~4)와 팀 이름·색을 정해요. 시청자는 `!팀 1` 또는 `!팀 이름`. 팀마다 기체 수가 같고 모두 같은 자동 조종을 써서 공평해요. 결과는 **최근 팀전 결과**에 남아요.

### 치즈 룰렛
- **등급**: 항목마다 자동·일반·✦ 희귀·★ 전설. 희귀는 금빛, 전설은 화면 번쩍 + 꽃가루로 축하해요.
- **빠르게 돌리기**: 한 번에 여러 회(기본 3회 이상)면 짧게 연달아 돌리고 마지막에 결과 요약을 보여줘요.
- **🎲 무료 룰렛**: 후원 없이 Xylem 창에서 돌리는 룰렛 (다음 게임·벌칙 정하기 등). 여러 개 만들 수 있어요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때). 새 Xylem 팩(1.1.0)은 Allmind에 들어 있어서 따로 적용할 필요 없어요.
