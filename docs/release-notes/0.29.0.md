## 바뀐 점
- **Xylem — 시청자 참여 기능 전용 창이 생겼어요.** 대시보드 오른쪽 위 **🎮 Xylem** 버튼(트레이 메뉴 "Xylem 열기")으로 따로 열리고, 메인 PC·아이패드·폰에서도 `http://<방송 PC 주소>:8080/xylem` 으로 열 수 있어요. 기능마다 왼쪽 메뉴에 칸이 있고, 대시보드 자리는 차지하지 않아요.
- **방송 중에도 업데이트돼요.** 룰렛·공중전 화면과 Xylem 창은 "팩"으로 따로 업데이트돼요. Xylem 창 위쪽에 새 팩이 보이면 **지금 적용** — Allmind를 다시 켜지 않고, OBS 오버레이도 알아서 새로고침돼요. **되돌리기**로 이전 팩이나 내장 팩으로 바로 돌아갈 수 있어요.
- **치즈 룰렛 (새 기능)**: OBS 브라우저 소스 `http://localhost:8080/roulette` (800×900 추천).
  - 1회 가격마다 1번 (예: 1,000 치즈 → 3,000 치즈 후원이면 3회), 한 번에 최대 횟수, 돌아가는 후원 종류(채팅·영상·미션)를 정할 수 있어요.
  - 항목·가중치·색은 Xylem 창에서 바꿔요. 확률(%)이 바로 보여요.
  - 결과는 Allmind가 공정하게 정해서 기록하고, 화면은 그 결과로 돌아가요. 중간에 OBS나 Allmind가 다시 켜져도 같은 결과로 이어서 보여줘요.
  - 기록에 **완료** 체크, **테스트 회전**, 대기 건너뛰기, 기록 지우기.
- **공중전**은 주소 그대로(`/dogfight`)예요. Xylem 창에서 주소 옵션을 골라 복사하고, 지금 시작·다음 판 보스전·테스트 출격·랭킹 초기화를 할 수 있어요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
