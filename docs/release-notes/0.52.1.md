## 바뀐 점
- **치지직 공식 연결이 더 튼튼해졌어요**: 토큰이 만료되기 전에 새 연결로 갈아타는 과정이 한 번 실패하면, 이제 바로 다시 시도해요. (예전에는 토큰이 끝날 때까지 기다렸다가 다시 연결했어요.)
- 연결할 때 쓰던 10초 대기 타이머를 응답이 오면 바로 정리해요 (보이는 변화는 없어요).
- 설정 창의 **치지직 연동** 안내 문구를 지금 동작에 맞게 고쳤어요: 이 로그인으로 채팅·후원·구독을 공식 API로 읽고, 방송 준비·채팅 보내기·관리 동작도 이걸로 해요. 앱 등록 단계의 권한 목록은 위에 나온 목록을 모두 고르라고 안내해요.
