## 바뀐 점
- **치지직 로그인: Client ID/Secret이 틀렸을 때 바로 알려줘요.** 로그인 버튼을 누르면 브라우저를 열기 전에 ID/Secret을 먼저 확인하고, 맞지 않으면 지금 저장된 값의 글자 수(ID는 보통 36자, Secret은 보통 43자)와 함께 알려줘요. 로그인 도중 `INVALID_CLIENT`가 나올 때도 같은 안내가 나와요.
- 붙여 넣은 Client ID/Secret에 섞인 공백·따옴표·보이지 않는 글자를 자동으로 지워요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
