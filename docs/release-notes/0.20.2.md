## 바뀐 점
- **작업표시줄 고정**: Allmind 창이 이제 작업표시줄에서 Edge가 아니라 **Allmind 아이콘·이름**으로 표시되고, 아이콘을 오른쪽 클릭해 "작업 표시줄에 고정"하면 Allmind 실행 파일을 가리키는 바로가기로 고정돼요. (창 자체는 Edge의 앱 모드로 열려요.)
- 고정한 아이콘이 업데이트 뒤에도 깨지지 않도록, 실행할 때마다 `%LOCALAPPDATA%\Allmind\Allmind.exe`에 최신 실행 파일 사본을 둡니다. 이 파일을 직접 고정해도 됩니다.
- 창 아이콘용 PNG 파비콘을 추가했어요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
