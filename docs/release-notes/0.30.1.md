## 바뀐 점
- **정리 (기능 변화 없음)**: 프로그램을 점검해서 더 이상 쓰지 않는 부분을 덜어냈어요.
  - 옛 이름(Stream Desk·Arkbird) 시절 설정을 찾아 가져오던 코드, 옛 시작 프로그램 바로가기 처리, 옛 폴더 정리 코드를 뺐어요. (지금 설정은 이미 Allmind 폴더에 있어서 영향 없어요. 다른 PC로 옮길 때는 "설정 옮기기"를 쓰세요.)
  - 릴리스마다 같은 파일을 Arkbird 이름으로 한 번 더 올리던 것도 그만했어요.
  - 화면에서 쓰지 않던 내부 기능 몇 개와 쓰지 않는 스타일을 지웠어요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
