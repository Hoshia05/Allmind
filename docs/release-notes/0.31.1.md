## 바뀐 점
- **설정 창 새 단장**: 한 곳에 몰려 있던 설정과 연동을 **기능별 칸**으로 나눴어요.
  - **기본** (OBS 연결 · 치지직 채널 · BGM·사운드보드 · 화면 소스 · 다른 기기에서 열기)과 **연동** (Google 계정 · 유튜브 아카이브 · 드라이브 자동 업로드 · 치지직 연동 · 치지직 리모컨 · 스트림덱), **관리** (설정 옮기기 · 기타)로 묶었어요.
  - 칸마다 **왜 필요한지**, **어떤 기능에 쓰이는지**, **단계별 연결 방법**이 있고, 끝난 단계에는 ✓가 붙어요.
  - 칸을 접어도 오른쪽에 상태(연결됨 · 설정 필요 · 안 씀 등)가 보여요. 처음이면 아직 안 된 첫 칸만 열리고, 열고 닫은 상태는 기억해요.
  - 저장하지 않은 설정이 있으면 아래에 **저장하고 다시 시작** 줄이 떠요.
- 스트림덱 칸에 연결된 플러그인 수가 보여요.
