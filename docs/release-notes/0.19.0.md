## 바뀐 점
- **💬 채팅 로그 저장 (SkyEye용)**: 녹화하는 동안 받은 치지직 채팅·후원을 영상과 같은 시간대로 `….markers.json`에 함께 저장해요. 일시정지한 구간은 빠지고, 1분마다 OBS 시계와 맞춰 봅니다.
- 이제 마크(⭐)를 한 번도 안 눌러도 채팅이 있으면 **방송마다** `….markers.json`이 생겨요. 영상과 같이 올려 주세요.
- 녹화가 끝나면 `💬 채팅 N개 · ⭐ N개 저장됨` 알림이 떠요.
- 설정 창의 **채팅 로그 저장 (SkyEye용)** 으로 끌 수 있어요(기본은 켜짐, 끄면 예전처럼 마크만 저장).
- Arkbird를 녹화 도중 다시 켜도 이어서 기록해요. 채팅 연결이 10초 이상 끊기면 그 구간을 파일에 표시해요.

## 업데이트 방법
Arkbird 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
