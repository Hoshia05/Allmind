## 고친 점
- **채팅이 "연결됨"인데 아무것도 안 들어오던 문제**에 대비했어요.
  - 채팅 서버에서 70초 동안 아무 신호가 없으면(연결이 조용히 끊긴 경우) 저절로 다시 연결해요.
  - 연결 중에서 30초 넘게 멈춰 있어도 다시 연결해요.
  - 채팅 제목 옆 **초록 점을 누르면** 바로 다시 연결해요.
- 메시지 하나를 못 읽어도 나머지 채팅은 그대로 보여요 (예전에는 한 묶음이 통째로 빠질 수 있었어요).
- 로그에 채팅 연결 과정이 남아요 (`[chat]` 줄) — 다음에 문제가 생기면 원인을 바로 찾을 수 있어요.
