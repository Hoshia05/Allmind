## 바뀐 점
- **스트림덱 플러그인**: 이제 주소를 붙이는 대신 진짜 스트림덱 플러그인으로 BGM·사운드보드를 조작해요. 스트림덱 앱에 **Allmind** 묶음이 생기고, 키를 놓은 뒤 설정에서 동작을 고르면 끝이에요.
  - **BGM**: 재생/일시정지 · 이 곡 재생(셋리스트에서 고르기, 곡 찾기 지원) · 다음/이전 곡 · 볼륨
  - **사운드보드**: 사운드 재생(폴더 목록에서 고르기, 다시 누르면 정지) · 정지 · 볼륨
  - 키에 지금 곡 제목, 재생 중인지(초록/주황), 볼륨이 실시간으로 보여요. Allmind가 꺼지면 **연결 안 됨**이 뜨고 다시 켜지면 저절로 붙어요.
- **설치**: 설정 창 → 스트림덱 카드 → **플러그인 설치** (방송 PC). 메인 PC는 카드에 나온 주소를 브라우저로 열어 받은 파일을 더블클릭하고, Allmind 키 설정의 **연결 → Allmind 주소**에 방송 PC 주소를 넣어 주세요.
- 예전 웹사이트 주소 방식도 그대로 돼요 (⭐ 마크는 아직 이 방식으로).

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때). 그다음 스트림덱 카드에서 플러그인을 설치하세요.
