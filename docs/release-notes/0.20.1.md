## 바뀐 점
- **새 색 테마**: 검정 바탕에 어두운 청록색(아머드 코어 6의 ALLMIND 같은 느낌)으로 바꿨어요. 대시보드, 설정 창, ⭐ 마크 페이지, 폰 홈 화면 아이콘 색이 모두 바뀝니다.
- **새 아이콘**: 육각형 네트워크(중심 노드와 연결된 노드들)로 Allmind 이름에 맞게 새로 그렸어요. 앱 상단, 설정 창, exe, 트레이, 폰 홈 화면 아이콘에 적용됩니다.
- 상단의 프로그램 이름이 대문자 간격 글꼴로 바뀌었어요.
- README 스크린샷을 새 화면으로 바꿨어요.

참고: 아이패드·폰에서 홈 화면에 추가해 둔 아이콘은 예전 그림이 남아 있을 수 있어요. 지우고 다시 추가하면 새 아이콘으로 바뀝니다.
