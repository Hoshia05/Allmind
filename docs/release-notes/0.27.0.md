## 바뀐 점
- **공중전에 보스전이 생겼어요.** 시청자 모두가 한편이 되어 거대한 공중요새 **BASTION**과 싸워요.
  - 방송인·매니저가 채팅에 `!보스`를 치면 다음 라운드가 보스전이 돼요. 주소에 `?boss=5`를 붙이면 5라운드마다 자동으로 보스전이 열려요.
  - 요새의 공격: 대공포 6문(요새가 부서질수록 하나씩 파괴), 유도 미사일 일제 사격, 그리고 예고선이 뜬 뒤 발사되는 **하전입자포**. 빔은 `!회피`(코브라)로 대부분 피할 수 있어요.
  - 체력이 절반 아래로 떨어지면 공격이 더 거세져요.
  - **참가 인원에 맞춰 난이도가 정해져요** — 기체 수가 많을수록 요새 체력·대공포 화력·미사일 수가 늘어나요. 혼자 참전하면 AI 윙맨 2기가 같이 나가요. 채팅으로 명령어를 열심히 쓰면 대체로 1분 안팎에 격파하고, 아무도 명령어를 안 쓰면 대체로 져요.
  - 끝나면 **MISSION ACCOMPLISHED / FAILED**와 함께 요새에 피해를 가장 많이 준 MVP가 나와요. 격파에 성공하면 MVP가 랭킹 1승, 마지막 일격을 넣은 사람이 격추 1을 얻어요.
- 화면 명령어 목록에 `!보스`를 추가했어요. README에 공중전 사용법을 정리했어요.
