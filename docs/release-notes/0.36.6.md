## 바뀐 점
- **작업 표시줄에 따로 뜨던 Allmind 아이콘 = Xylem 창**: 로그를 보니 Allmind는 제목이 "Allmind"인 창만 고정 아이콘에 묶고 있었고, 제목이 "Xylem"인 Xylem 창은 같은 아이콘으로 따로 떴어요. 이제 Xylem 창도 고정해 둔 Allmind 아이콘 아래로 묶여요.
- **로그 정리**: 메인 PC의 VTube Studio가 꺼져 있을 때 다시 연결할 때마다 로그에 한 줄씩 쌓이던 것을, 이유가 바뀔 때나 한 시간에 한 번만 남기게 했어요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
