## 고친 점
- **채팅 칸 크기를 바꾸면 맨 위로 올라가던 문제**를 고쳤어요. 패널 크기를 바꾸거나, 채팅·후원 탭을 오가거나, 채팅을 숨겼다 켜도 맨 아래(새 채팅)에 그대로 있어요. 직접 위로 올려 둔 경우에는 그 자리를 지켜요.
- **대시보드를 켜면 BGM이 저절로 나오던 문제**를 고쳤어요. OBS가 켜지면서 BGM을 혼자 틀면, 방송 전에는 멈춰 둬요.
- **방송이 시작되면 BGM이 재생돼요.** 영도가 나오는 중이면 영도가 끝난 뒤에 나와요. 방송 중에 Allmind만 다시 켠 경우에는 건드리지 않아요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
