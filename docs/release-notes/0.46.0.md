## 바뀐 점
- **🧪 시청자 추첨 테스트** (Xylem 팩 1.6.0 — **지금 적용**): 시청자가 없어도 Xylem 창 → 시청자 추첨에서 **테스트 추첨 (10 · 30 · 100명)**을 누르면 처음부터 끝까지 해 볼 수 있어요.
  - 12초 동안 가짜 시청자가 들어오고 (구독자·방송인·중복 참여는 실제처럼 걸러져요), 저절로 뽑고, 당첨자가 채팅을 몇 번 쳐요.
  - 연출 · 교신 · **목소리(TTS)** · 대시보드 채팅 🏆 강조까지 진짜와 똑같이 나와요. 목소리를 들으려면 OBS 오버레이가 연결돼 있어야 해요.
  - 테스트 중에는 진짜 채팅을 받지 않고, 당첨 기록·지난 당첨자·방송 리포트에 남지 않고, 채팅에도 알리지 않아요. 오버레이에 **🧪 테스트** 표시가 떠요. **취소**나 **끝내기**로 언제든 멈출 수 있어요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때). 그다음 Xylem 창에서 새 팩이 보이면 **지금 적용**.
