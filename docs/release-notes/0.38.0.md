## 바뀐 점
- **텍스트 (Xylem → 🔤 텍스트)**: 방송 화면에 글자를 띄워요. OBS 텍스트 소스를 열 필요 없이 Xylem 창에서 바로 써요.
  - OBS에 브라우저 소스 하나만 넣으면 돼요: `http://localhost:8080/text?id=1` (1920×1080). 상자를 여러 개 만들 수 있고 상자마다 주소가 달라요.
  - 쓰고 **보내기** (Ctrl+Enter). **실시간**을 켜면 치는 대로 바로 나가요. 보낸 글자는 목록에 남아서 누르면 다시 띄워요. **숨기기 / 보이기** 한 번에.
  - 글꼴(한글 웹 글꼴 30여 개 + 이 PC에 설치된 글꼴), 크기, 굵기, 기울임, 자간, 줄 간격, 정렬, 글자 색·그라데이션, 외곽선, 그림자, 배경 상자(색·진하기·여백·둥글기·테두리), 위치(9곳 + 거리), 최대 너비 — 움직이는 대로 방송에 바로 반영돼요.
  - 애니메이션: 나타날 때(서서히·밀려오기·톡·줌·흐림·타자기), 글자가 바뀔 때, 계속(둥실둥실·두근두근·흔들기·빛나기·무지개·깜빡이기·흐르는 전광판), 빠르기.
  - 스타일 모음: 자막 · 공지 배너 · 전광판 · 네온 · 손글씨 메모 · 그라데이션 제목. 지금 스타일에 이름을 붙여 저장할 수도 있어요.
  - 미리보기 창이 실제 오버레이와 똑같이 보여 줘요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때). 그다음 Xylem 창에서 새 팩(1.4.0)이 바로 쓰여요.
