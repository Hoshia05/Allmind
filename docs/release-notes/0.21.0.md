## 새 기능
- **방송 준비** (대시보드 위쪽 버튼): 제목·카테고리·태그를 한 번 적고 **적용**하면 치지직 방송 설정, 유튜브 아카이브 제목, 녹화 파일 이름에 한꺼번에 들어가요. 폰에서도 돼요.
- **유튜브 아카이브 지키기**: 방송마다 **비공개 · 자동 시작** 방송을 미리 준비해서, 지난 방송 결과 화면 때문에 유튜브가 시작되지 않는 문제를 없앴어요. 방송 중에 공개로 바뀌면 바로 비공개로 되돌리고, 유튜브가 시작되지 않으면 대시보드에 빨간 알림이 떠요.
- **드라이브 자동 업로드**: 녹화가 끝나면 영상과 마크 파일을 `2026-10-26 - 방송 제목` 이름으로 구글 드라이브에 올려요. 방송·녹화 중에는 쉬고, 끊겨도 이어서 올려요. 원본 파일은 그대로예요.
- **시청자 정보**: 채팅·후원 목록에서 닉네임을 누르면 그 시청자의 채팅 수, 최근 채팅, 후원·구독 기록이 나와요.

## 처음 한 번 설정
설정 창 → **연동** 카드에서 Google 로그인(유튜브·드라이브)과 치지직 로그인을 해 주세요. 카드 안에 단계별 안내가 있어요. 유튜브는 Allmind가 만든 **새 스트림 키**를 OBS Multi-RTMP의 유튜브 대상에 한 번 넣어야 해요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
