## 바뀐 점
아래 변경은 0.51.0에 이미 들어가 있었는데, 0.51.0 안내에서 빠졌어요. 이번 버전에서 정식으로 알려 드려요.

- **치지직 공식 API로 전환**: 채팅·후원(영도 포함)·구독을 이제 치지직 **공식 Open API**(세션)로 읽어요. 치지직 연동 로그인이 되어 있으면 자동으로 공식 연결을 써요 (설정 창·점검에 "공식 API"로 보여요). 토큰이 만료되기 전에 새 연결을 먼저 열어서 끊김 없이 이어지고, 끊기면 알아서 다시 연결해요. 로그인이 없는 사람(공개 저장소를 쓰는 다른 분)은 예전처럼 로그인 없이 읽는 **"비공식 연결 (치지직 로그인 없이)"**로 계속 쓸 수 있어요.
- **닉네임 카드의 관리 동작도 공식 API**: 임시 제한, 활동 제한(과 해제), **메시지 숨기기**, **공지로 올리기**. 이제 OBS의 리모컨 독이 없어도 돼요.
- **필요한 권한 (CHZZK Developers의 내 앱에서 켜고, 설정 창에서 치지직 로그인을 다시 해 주세요)**: 채팅 메시지 조회, 후원 조회, 구독 조회, 채팅 메시지 쓰기, 채팅 공지 쓰기, 활동제한 조회, 활동제한 쓰기, **채널 구독자 조회**(새로 필요), **유저 정보 조회**(새로 필요), 방송 설정 조회, 방송 설정 변경. 빠진 권한은 점검과 설정 창에 이름이 나와요. 권한이 없는 기능만 빠지고 나머지는 그대로 돼요.
- 새 설정 두 가지 (기본은 꺼짐, 설정 창 → 치지직 채널):
  - **비공식 연결 (미션 후원 포함)**: 공식 API에는 미션 후원이 없어서, 미션 후원이 필요하면 켜세요. 켜면 공식 연결 대신 옛 방식으로 읽어요 (둘을 함께 쓰지는 않아요). 공식 연결에 문제가 생겼을 때 바로 예전 방식으로 돌아가는 스위치로도 쓸 수 있어요.
  - **시청자 수 · 최고 시청자 · 19세 표시 (비공식 조회)**: 공식 API에는 내 방송의 시청자 수가 없어요. 켜면 이 숫자만 옛 방식으로 가져와요.

## 사라지거나 달라진 것
- **시청자 수 · 최고 시청자 · 시청자 그래프 · 19세 표시**: 위 설정을 켜지 않으면 "–"로 보이고, 방송 보고서의 최고 시청자도 비어요. "방송 중"과 방송 시간은 **OBS의 송출 상태** 기준이에요. 제목·카테고리는 방송 준비에 저장된 값이에요.
- **메시지 삭제 → 메시지 숨기기** (치지직 공식 API는 삭제가 아니라 숨기기만 해요).
- **상단 고정 → 공지로 올리기**: 시청자의 글 그대로가 아니라 같은 내용을 새 공지(100자까지)로 올려요.
- **채팅 운영자 임명/해제**: 공식 API에 없어서 "치지직 스튜디오에서 열기" 링크로 바뀌었어요.
- **닉네임 카드**: 팔로우한 날짜와 메시지·제한 횟수는 공식 API에 없어서 빠졌어요 ("활동 제한 중" 표시는 남아요).
- **채팅 목록**: 연결할 때 최근 채팅 50개를 채워 주던 기능, 다른 사람이 숨긴 글을 회색으로 표시하는 기능, 시스템 안내 줄은 공식 API에 없어서 빠졌어요 (SkyEye 채팅 로그와 StreamMaid로 가는 채팅은 원래 실시간 줄만 써서 영향이 없어요).
- **구독 뱃지**: 이미지는 빠지고 개월 수·티어는 구독자 목록으로 채워요 (구독자 전용 추첨은 그대로 돼요).
- 후원·구독 줄의 시각은 받은 시각이에요 (공식 이벤트에 시각이 없어요).
- 바뀌지 않은 것: 리모컨의 넘기기·알림 정지·영도 건너뛰기 버튼, 방송 준비, 채팅 보내기.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때). 그다음 CHZZK Developers에서 권한을 켜고 설정 창 → 치지직 연동에서 **다시 로그인**해 주세요 (점검에서 "공식 API"가 보이면 돼요). 방송 전에 비공개 테스트 방송으로 채팅·후원이 잘 들어오는지 한 번 확인해 주세요.
