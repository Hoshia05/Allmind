## 바뀐 점
- **드라이브 업로드를 원하는 폴더에.** 설정 창 → 연동 → 드라이브 자동 업로드의 **올릴 폴더**에 드라이브 폴더 링크를 붙여 넣으면, 녹화가 그 폴더에 올라가요 (비워 두면 예전처럼 "Allmind 녹화" 폴더).
  - 직접 만든 폴더에 올리려면 드라이브 권한이 더 필요해서, 이번 업데이트 후 **Google 로그인을 한 번 더** 해 주세요. 허용 화면이 2번 나오면: 첫 번째(유튜브)는 **아카이브 채널(브랜드 계정)**, 두 번째(드라이브)는 **그 폴더가 있는 내 계정**을 고르세요.
- **유튜브: 다른 채널로 로그인하면 알려줘요.** 저장된 스트림 키가 지금 로그인한 채널에 없으면 키를 지우고 "스트림 키 만들기를 다시 눌러 OBS Multi-RTMP에 새 키를 넣어 주세요"라고 알려줘요. (이번처럼 다른 계정의 채널로 송출되는 걸 막기 위해서예요.)
- **업데이트 후 처음 실행한 exe가 옛 버전으로 남던 문제를 고쳤어요.** 0.24.0에서 넣은 "처음 실행한 exe도 새 버전으로 바꾸기"가, 업데이트 파일을 먼저 지우는 정리 작업 때문에 실제로는 동작하지 않고 있었어요. 이번 업데이트부터 제대로 바뀌어요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
