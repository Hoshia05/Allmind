## 바뀐 점
- **정리**: 화면의 말을 통일했어요 — **리모컨**(리모콘), **광고 스킵**(광고 넘기기·건너뛰기), **Google**(구글).
- 영어로 나오던 안내를 한국어로: 화면이 뜨기 전 **OBS 기다리는 중…**, 연결이 안 될 때 **Allmind에 연결할 수 없어요**, 셋리스트가 비었을 때 **셋리스트에 곡이 없어요**.
- 설정 창: OBS가 Allmind 밖에서 켜졌을 때의 안내가 대시보드의 **OBS 다시 켜기**와 **OBS 바로가기 고치기**를 알려 줘요.
- README: 시청자 정보의 관리 버튼, 폰 하단 탭(할 일·Xylem), OBS 바로가기 고치기 안내를 최신으로.
- 안 쓰는 코드와 스타일을 조금 지웠어요 (기능은 그대로예요).
