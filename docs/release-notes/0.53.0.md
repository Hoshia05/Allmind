## 바뀐 점
- **Xylem 화면 펫 (`🐾 화면 펫`) 기능 확장** (Xylem 팩 `1.6.2`):
  - **시청자 채팅 명령어:** `!점프`, `!대시`, `!춤`, `!자장`과 `!캐릭터 <이름/번호>`로 원하는 캐릭터 고르기(시청자별 저장).
  - **시청자끼리 상호작용:** `!안아 <닉네임>`, `!툭 <닉네임>` 및 지나가다 가끔 하는 펫 인사.
  - **후원·구독 축하 & 구독자 표시:** 후원/구독 시 반짝이 축하 연출(치즈/구독 모두 공정한 꾸미기 전용), 구독자 닉네임 `★` 테두리 표시.
  - **모두 함께 & 올라갈 자리:** 패널에서 **모두 점프 / 모두 춤추기 / 가운데 모이기 / 흩어지기**, 웹캠·채팅창 위 등 1920×1080 기준 **올라갈 자리(발판)** 설정 추가.
