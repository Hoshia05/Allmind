## 바뀐 점
- **설정 옮기기 (내보내기 · 가져오기)**: 설정 창의 새 칸 **설정 옮기기 (다른 PC로)** 에서 Allmind 설정을 파일 하나로 만들고, 다른 PC의 Allmind에서 그대로 불러올 수 있어요.
  - 들어가는 것: 설정(OBS 비밀번호·소스·폴더·치지직 채널·스트림덱 키 등), Google·치지직 연동 로그인, 유튜브 스트림 키 연결, BGM 셋리스트 순서·볼륨, 사운드보드 볼륨, 공중전 랭킹 등. (드라이브 업로드 대기열은 이 PC의 파일이라 빠져요. 대시보드 패널 배치는 브라우저마다 따로라 옮겨지지 않아요.)
  - **내가 정한 비밀번호로 암호화**돼요 (scrypt + AES-256-GCM). 비밀번호 없이는 아무도 열 수 없고, 비밀번호를 잊으면 복구할 수 없어요. 비밀번호가 틀리거나 파일이 손상되면 알려줘요.
  - 가져오기는 먼저 **열어 보기**로 어느 PC에서 언제 만든 파일인지, 무엇이 들어 있는지 확인한 뒤 적용해요. 적용 전 지금 설정은 설정 폴더의 "가져오기 전 백업" 폴더에 남겨 둬요.
  - 폴더 위치가 다른 PC라면 적용 후 설정에서 BGM·사운드보드 폴더를 고쳐 주세요. 치지직 연동 로그인은 한 번 쓰면 바뀌는 방식이라, 두 PC에서 번갈아 쓰면 한쪽은 다시 로그인해야 할 수 있어요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
