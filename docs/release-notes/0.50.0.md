## 새 기능
- **📱 폰 모드**: Galaxy Z Fold 7(커버·메인 화면)과 iPad 세로 화면에 맞춘 모바일 화면이 생겼어요.
  - 아래쪽 탭이 **홈 · 채팅 · 음악 · 화면 · 더보기** 5개로 바뀌었어요.
  - **홈** 탭에 마이크, ★ 마크, 장면 전환, BGM 재생/넘기기, 리모컨(넘기기·광고 스킵·알림 정지), 고정한 OBS 소스/오디오, 오늘 할 일, 방송 준비·점검 버튼을 큰 터치 버튼으로 모았어요.
  - **화면** 탭을 보고 있을 때만 방송 화면·영도·알림 화면 미리보기를 받아와서 방송 PC와 모바일 데이터 부담을 줄였어요.
  - **Fold 메인 화면·iPad 세로**에서는 **홈과 채팅을 좌우 2열**로 나란히 보여줘요 (iPad 가로는 기존 PC 화면 그대로예요).
  - **더보기** 탭에서 Xylem, 방송 기록, 치지직 리모컨, 방송 준비, 점검, 이 기기 설정과 전체 할 일 목록을 열 수 있어요.
- **화면 전환 스위치**: ⚙(이 기기 설정) → **화면**에서 **자동 / 폰 모드 / PC 화면**을 기기마다 따로 고를 수 있어요.

## 알아 두세요
- 가상 OBS·가상 치지직 환경의 크롬 브라우저(412×915, 884×1000, 1024×1366, 1366×1024)에서 시험했어요. 실제 Fold 7과 iPad Safari에서의 화면 배치는 업데이트 후 한 번 확인해 주세요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
