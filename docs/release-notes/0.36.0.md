## 바뀐 점
- **치즈 룰렛이 투네이션처럼 바뀌었어요**
  - **룰렛마다 가격**: 시청자가 **정확히 그 금액**(또는 2배·3배…)으로 후원할 때만 돌아가요. 다른 금액은 일반 후원이라 안 돌아가요.
  - **후원 룰렛 여러 개**: 예) 1,004 치즈 작은 룰렛, 10,004 치즈 큰 룰렛. 가격이 서로 배수면 설정 화면에 경고가 떠요.
  - **룰렛 안내판** (새 OBS 브라우저 소스 `/roulette-board`): 룰렛마다 가격·항목·확률·등급(✦ 희귀 / ★ 전설)을 보여 줘요. 항상 / 몇 분마다 잠깐 / 명령어가 나올 때 중에서 고르고, 룰렛이 도는 동안엔 숨어요.
  - **!룰렛 채팅 명령어**: 시청자가 치면 Allmind가 채팅으로 확률을 알려 줘요 (치지직 연동 필요).
