## 바뀐 점
- **보안: Allmind는 이제 자기 화면에서 온 명령만 받아요.** 지금까지는 같은 PC나 같은 네트워크의 브라우저에 열린 *아무 웹사이트*나 Allmind에 몰래 명령을 보낼 수 있었어요 (방송 PC의 브라우저라면 설정까지). 이제는 막혀요.
  - 다른 사이트에서 온 요청, 다른 사이트의 이미지로 누르는 스트림덱 버튼, 낯선 도메인 이름으로 들어오는 요청(DNS 리바인딩)을 거절하고 `allmind.log`에 `[guard]`로 남겨요.
  - 대시보드·설정 창·Xylem·OBS 오버레이·스트림덱 플러그인·/mark 페이지는 그대로 돼요. 바꿀 것 없어요.
- **OBS 위치에는 obs64.exe만**: 설정의 OBS 위치에 다른 프로그램을 넣을 수 없고, Allmind는 obs64.exe가 아닌 파일은 실행하지 않아요.
- 메인 PC 등에서 IP 주소나 PC 이름이 아닌 다른 이름으로 대시보드를 연다면 (거의 없어요) 설정 파일의 `server.allowedHosts`에 그 이름을 넣어 주세요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
