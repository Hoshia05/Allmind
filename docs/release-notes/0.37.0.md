## 바뀐 점
- **채팅 한 곳에 — 치지직 + 유튜브**: 대시보드 채팅에 유튜브 방송 채팅도 같이 나와요. 줄마다 어느 플랫폼인지 작은 아이콘이 붙어요.
  - 유튜브 채팅은 유튜브 방송이 **비공개가 아닐 때만** 있어요. 설정 창 → 유튜브 아카이브 → **공개 범위** (비공개 · 일부 공개 · 공개)를 새로 골라요. 기본은 지금처럼 비공개예요.
  - 10초마다 가져와서 조금 늦게 보이고, YouTube API 할당량을 써요 (다 쓰면 그날은 멈춰요). 끄려면 같은 칸의 **유튜브 채팅도 보여 주기**를 끄세요.
  - 유튜브 쪽은 멤버 · 모더레이터 · 슈퍼챗 · 멤버십을 표시해요. 게임·룰렛·방송 기록에는 치지직 채팅만 들어가요.
- **치지직 구독 배지**: 닉네임 앞에 구독 배지(마우스를 올리면 개월 수), 채널 시청자 배지, 인증 표시가 나와요. 닉네임을 눌렀을 때 나오는 카드에도요.
- **위플챗 탭을 없앴어요**: 채팅 칸의 위플챗 탭과 설정 창의 위플챗 소스 칸이 빠졌어요 (OBS 쪽은 바꿀 게 없어요). 후원 탭의 도네 알림 화면은 그대로예요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
