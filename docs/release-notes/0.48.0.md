## 새 기능
- **🔑 어시스턴트 연결 (API 토큰)**: 어시스턴트(AI 비서) 같은 다른 프로그램이 Allmind와 안전하게 연결할 수 있어요.
  - 설정 창 → **API 토큰** 칸을 처음 열면 토큰이 만들어져요. **한 번만 보이니** 복사해서 어시스턴트 설정에 붙여 넣어 주세요. 잃어버리면 **새로 만들기**를 누르면 돼요 (예전 토큰은 바로 못 쓰게 돼요).
  - 어시스턴트는 채팅·후원·⭐ 마크·방송 상태 소식을 받고, **장면 · ⭐ 마크 · BGM · 사운드보드 · 할 일**만 조작할 수 있어요.
  - **방송 켜고 끄기, 녹화, 파트 나누기, 제목·카테고리, 채팅 보내기, 시청자 관리, 설정, 업데이트는 토큰으로도 절대 못 해요.**
  - 장면은 **어시스턴트가 바꿔도 되는 장면**에 체크한 것만 바꿀 수 있어요. 처음에는 아무것도 체크돼 있지 않아요. 바탕화면이나 개인 화면이 보일 수 있는 장면은 체크하지 마세요.
  - 어시스턴트가 연결돼 있어도 방송 PC에 부담이 늘지 않아요 (대시보드를 연 것으로 치지 않아요).
- **🎚️ 스트림덱 플러그인 1.2.0 — 신호 키**: 어시스턴트용 **말하기 · 음소거 · 끄기** 키가 생겼어요. 말하기는 짧게 누르면 켜고 끄기, 누르고 있으면 누르는 동안만 들어요. Allmind는 신호만 전달하고, 어시스턴트가 알아서 처리해요.
- **🌐 다른 기기에서 열기 — Tailscale**: 설정 창 → **다른 기기에서 열기**에서 세 가지 중에 고를 수 있어요.
  - **끄기**: 이 PC에서만 열려요.
  - **같은 네트워크 + Tailscale**: 지금처럼 같은 공유기의 기기에서 열리고, 내 Tailscale 기기에서도 열려요. (지금 쓰던 설정은 그대로 이걸로 이어져요.)
  - **Tailscale만**: 내 Tailscale 계정에 등록한 기기에서만 열려요. 밖에서 폰 데이터로도 열 수 있고, 같은 와이파이라도 Tailscale이 없는 기기는 못 열어요.
  - 칸에 같은 네트워크 주소와 Tailscale 주소가 따로 보여요. 다른 기기에서 열 때는 **PIN을 켜 두는 걸 추천해요**.
  - Tailscale의 공유 기능(Serve·Funnel)을 거쳐 들어오는 연결은 어떤 방식에서도 막아요 (그대로 두면 PIN 없이 방송 PC처럼 보였을 거예요).

## 알아 두세요
- 스트림덱 신호 키를 쓰려면 **메인 PC에서 스트림덱 플러그인을 다시 설치**해 주세요 (설정 창 → 스트림덱 칸).
- **Tailscale만**을 고르면 메인 PC 스트림덱도 Tailscale이 켜져 있어야 하고, 플러그인 연결 주소를 방송 PC의 Tailscale 주소(100.…:8080)로 바꿔야 해요.
- 끄기 ↔ 다른 방식으로 바꿀 때는 Allmind가 잠깐 다시 시작해요. 같은 네트워크 ↔ Tailscale만은 바로 바뀌고, 더는 허용되지 않는 기기는 연결이 끊겨요.
- 아직 가상 OBS·가상 스트림덱으로만 시험했어요. 실제 Tailscale(폰 데이터로 열기), 실제 스트림덱 앱의 신호 키는 처음 쓸 때 확인해 주세요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
