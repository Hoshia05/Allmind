## 새 기능
- **방송·녹화를 대시보드에서 켜고 꺼요**: 위 막대의 **LIVE / OFFLINE** 표시를 누르면 **방송 · 녹화** 창이 열려요. 시작은 한 번, 끄기는 **두 번** 눌러야 해요 (실수 방지). 녹화 일시정지·이어서도 돼요. 방송 전 점검에 문제가 남아 있으면 시작 버튼 아래에 알려 줘요.
- 녹화 중이면 표시 옆에 **REC**, 일시정지면 **녹화 멈춤**이 붙어요. OBS는 송출 중인데 치지직에 아직 방송이 안 보이면 **송출 중**으로 보여요.
- **OBS 패널**: **＋ 고르기**로 자주 켜고 끄는 소스(웹캠, 공지 텍스트…)와 오디오(디스코드, 데스크톱 소리…)만 골라 두세요. 👁 보이기/숨기기, 🔊 음소거, 볼륨, 소리 크기 막대가 생겨요. 처음엔 비어 있어서 대시보드가 복잡해지지 않아요.
  - 넓은 화면: 사운드보드 옆 **OBS** 탭 · 폰: 아래 **할 일·OBS** 탭 (OBS 칸은 ▸로 펴요)
  - OBS에서 소스·장면 이름을 바꿔도 따라가요. 그룹 안의 소스도 고를 수 있어요.

## 알아 둘 것
- 소리 크기 막대는 OBS가 원래 보내 주는 값을 써서, 방송 PC에 일이 더 생기지 않아요.
