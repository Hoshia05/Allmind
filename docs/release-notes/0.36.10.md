## 바뀐 점
- **OBS를 직접 켜도 괜찮게**: 영도 클릭 전달·광고 넘기기·치지직 리모컨은 OBS가 Allmind 옵션으로 켜져야 돼요. OBS를 바탕화면·작업 표시줄 아이콘으로 직접 켜면 이 기능들이 꺼져 있었죠.
  - 대시보드에 알림과 함께 **OBS 다시 켜기** 버튼이 떠요 — OBS를 정상적으로 닫았다가 Allmind 옵션으로 다시 켜요 (방송·녹화 중에는 안 눌려요).
  - 설정 창 → OBS → **OBS 바로가기 고치기**: 바탕화면·작업 표시줄·시작 메뉴의 OBS 아이콘에 옵션을 넣어 줘요. 한 번 해 두면 OBS를 어떻게 켜도 다 돼요. (모든 사용자용 시작 메뉴 아이콘은 관리자 권한이 필요해서 못 고칠 수 있어요.)
- 클릭 전달 안내 문구를 한국어로 바꿨어요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
