## 바뀐 점
- **스트림덱 연동 (새 기능)**: 스트림덱 키 하나로 BGM과 사운드보드를 조작할 수 있어요. 키에 **웹사이트(Website)** 동작을 놓고 Allmind 주소를 붙여 넣으면 끝이라 플러그인은 필요 없어요.
  - 방송 PC 설정 창 → **스트림덱** 카드의 **키에 붙일 주소 목록**에서 원하는 동작의 주소를 **복사**해 붙여 넣으세요. 스트림덱 동작에서 **백그라운드에서 접근(Access in background)** 을 꼭 체크하세요.
  - 할 수 있는 것: BGM 재생/일시정지·재생·일시정지·다음 곡·이전 곡·볼륨, 사운드보드 파일별 재생·정지·볼륨, ⭐ 마크.
  - 메인 PC와 방송 PC, 스트림덱이 여러 대여도 모두 같은 Allmind 하나를 써요. (같은 키를 두 곳에서 토글하면 서로 엇갈릴 수 있으니 `재생`/`일시정지`를 따로 쓰는 게 안전해요.)
  - **비밀 키(선택)**: 설정 창에서 정해 두면 키가 없는 요청은 거절해요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
