## 바뀐 점
- **작업 표시줄에 Allmind가 두 개로 나뉘던 문제 고침**: 설정 창이 고정해 둔 Allmind 아이콘과 따로 뜨던 문제예요. Allmind는 창을 연 직후 15초 동안만 "이 창은 Allmind예요" 표시를 붙였는데, 창이 늦게 뜨거나 Edge가 표시를 지우면 다시 붙이지 않았어요. 이제 설정 창이 열리거나 선택될 때마다 확인해서, 표시가 없으면 다시 붙여요.

## 그래도 따로 뜬다면
고정해 둔 아이콘이 예전에 exe 파일을 직접 고정한 것이면 다르게 취급돼요. 그 아이콘을 **작업 표시줄에서 제거**하고, 실행 중인 Allmind 창의 아이콘을 오른쪽 클릭 → **작업 표시줄에 고정**해 주세요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
