## 바뀐 점
- **🔁 무한 반복 (게임 음악처럼 끝없이)**: 셋리스트의 곡 옆 🔁를 누르면, 게임 안에서처럼 이음새 없이 계속 이어지는 버전을 만들어요. 그 곡은 멈추거나 다른 곡을 고를 때까지 계속 반복돼요.
  - Allmind가 곡을 분석해서 **반복 구간을 자동으로** 찾아요 (게임 립 파일에 LOOPSTART 태그가 있으면 그걸 써요).
  - **▶ 이음새 듣기**로 이어지는 부분을 미리 들어 보고, 필요하면 시작·끝을 ±10 ms / ±100 ms씩 고쳐요.
  - **저장하고 만들기** → 1~2분 동안 무한 반복 파일을 한 번 만들어요 (곡당 약 120 MB, 방송에는 영향 없어요). 원본 파일은 그대로예요.
  - 재생 중에는 "🔁 무한 반복"이라고 나오고, 진행 막대는 원곡 기준 위치를 보여 줘요. **무한 반복 끄기**를 누르면 지금 위치에서 원곡으로 넘어가 자연스럽게 끝나요.
  - 처음 한 번은 **ffmpeg**(음악 도구, 약 100 MB)를 받아야 해요 — 루프 창에서 버튼 한 번.
  - 참고: 약 20분 뒤와 그 뒤 1시간마다 OBS가 파일을 바꿔 열 때 아주 짧은 끊김이 있을 수 있어요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
