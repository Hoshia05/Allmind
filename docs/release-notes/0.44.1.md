## 바뀐 점
- **방송 준비: "유튜브 제목 · 녹화 파일 이름도 같이 바꾸기" 체크**가 생겼어요.
  - 방송 전에는 켜져 있어서 지금처럼 세 곳에 한 번에 들어가요.
  - **방송 중에 열면 꺼져 있어요**: 콘텐츠를 바꾸면서 제목을 고쳐도 **치지직만** 바뀌어요. 유튜브 아카이브 제목은 그대로고, 지금 녹화는 드라이브에 **지금까지의 이름 그대로** 올라가요.
  - 끈 상태에서는 유튜브 제목·파일 이름 칸이 흐려지고 지금 값이 보여요. 필요하면 체크를 켜고 적용하면 돼요.
- 같이 바꾸기를 켠 채 녹화 중에 제목을 바꾸면, 드라이브 이름은 **그 녹화 동안 가장 오래 걸려 있던 제목**으로 정해진다고 결과에 알려 줘요 (직접 적은 파일 이름이 있으면 그 이름).

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
