## 바뀐 점
- **VTube Studio 던지기**: 메인 PC의 VTube Studio에 Allmind가 플러그인으로 연결돼요. 시청자가 채팅으로 `!던지기` (또는 `!던져`)를 치면 물건이 날아와 모델 머리에 맞고, 고개가 흔들리고 튕겨 나가요. 던진 사람 이름은 안 나와요.
  - Xylem 창 → **VTube Studio**: 연결(메인 PC 주소), 명령어·쿨다운·최대 개수·크기·흔들림·빨갛게 번쩍·밀려나기·맞을 때 VTS 단축키, 후원으로 던지기(기본 꺼짐).
  - **조준점 꺼내기**: VTube Studio에 나온 과녁을 머리로 끌어다 놓으면 맞는 위치가 저장돼요.
  - 던질 물건은 이미지를 올려서 바꿀 수 있어요 (없으면 치즈·하트·별).
- **표정 (준비 중)**: 나중에 시청자가 머리·옷 등을 바꾸는 기능을 위해 VTS 표정 목록과 켜기/끄기 시험을 넣어 뒀어요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때). 그다음 Xylem 창의 **VTube Studio**에서 연결하세요.
