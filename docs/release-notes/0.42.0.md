## 바뀐 점
- **스트림덱 키 추가** (플러그인 1.1.0 — 설정 창 **연동 → 스트림덱**에서 **플러그인 설치**를 한 번 더 눌러 주세요. 메인 PC는 받은 파일을 다시 더블클릭):
  - **BGM · 🔁 무한 반복 켜기/끄기**: 지금 재생 중인 곡의 무한 반복을 켜고 꺼요. 키에 **켜짐**(초록) · **만드는 중 %** · **꺼짐**이 보여요. 셋리스트의 🔁에서 루프 지점을 한 번 저장해 둔 곡만 돼요 (확인 안 한 이음새가 방송에 나가지 않게).
  - **할 일 (새 동작)**: **다음 항목 체크** — 오늘 할 것에서 아직 안 한 첫 항목을 체크해요. 키에 그 항목 이름과 남은 개수가 보이고, 다 하면 **다 했어요!** 녹화 중이면 ⭐ 마크도 남아요. **마지막 체크 되돌리기**도 있어요.
- 플러그인 없이 쓰는 웹사이트 동작 주소도 추가: `/deck/bgm-loop`, `/deck/todo-next`, `/deck/todo-undo`.
