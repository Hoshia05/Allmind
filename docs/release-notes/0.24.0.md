## 바뀐 점
- **업데이트하면 처음 실행한 exe 파일도 같이 새 버전으로 바뀌어요.** 전에는 앱만 업데이트되고 다운로드 폴더의 `Allmind-0.xx.x.exe` 는 옛날 버전 그대로라서, 그 파일을 다시 열 때마다 옛 버전이 켜지고 또 업데이트를 눌러야 했어요. 이제 업데이트가 끝나면 그 파일이 같은 위치·같은 이름으로 최신 버전이 되어서, 다음부터는 그냥 열기만 하면 돼요.
  - 파일 이름의 버전 숫자는 그대로 남을 수 있어요(바로가기가 깨지지 않게 이름은 건드리지 않아요). 실제 버전은 설정 창에서 확인하고, 이름은 원하면 직접 `Allmind.exe` 로 바꿔도 돼요.
  - 파일이 읽기 전용 위치에 있거나 다른 프로그램이 잡고 있으면 건너뛰고, 다음 실행 때 다시 시도해요.
  - **이번 0.24.0으로 올리는 업데이트부터** 적용돼요.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때).
