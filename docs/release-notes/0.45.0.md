## 바뀐 점
- **🎟 시청자 추첨** (Xylem 팩 1.5.0 — 팩은 Xylem 창에서 **지금 적용**): 채팅으로 시청자를 모아서 1~10명을 뽑아요. Xylem 창 → **시청자 추첨**, OBS 브라우저 소스 `http://localhost:8080/draw` (1920×1080).
  - **참여 열기**: 30초 · 1분 · 3분 · 직접 입력 · 제한 없음. 시청자가 채팅에 **!참여**를 치면 한 사람당 한 번 들어와요. 패널과 오버레이에 카운트다운, **마감**·**+30초** 버튼. "최근 N분 안에 채팅한 사람" 방식도 있어요.
  - **공정해요**: 누가 뽑힐지는 Allmind가 연출 전에 정하고 오버레이는 보여 주기만 해요. 모두 같은 확률이고, 후원·구독은 확률에 영향이 없어요. 거르기: 구독자만 · 지난 당첨자 제외 · 방송인/매니저와 유튜브 채팅은 제외.
  - **✈ 공중전 출격** (30~45초): 참가자 모두가 닉네임을 단 전투기로 출격하고, 진 사람은 미사일·대공포·적기·번개·협곡·궤도포에 격추돼요 ("○○ 격추!" 교신). 마지막에 슬로모션, **임무 완수**, 당첨 카드. 1명~150명까지 읽기 쉽게 보여요. **🎰 룰렛** 모양도 있어요.
  - **당첨자 채팅**: 당첨자의 채팅이 오버레이에 교신으로 나오고 대시보드 채팅에서 **🏆 당첨**으로 강조돼요. 읽는 시간을 정하거나 **끝내기**. 대답이 없으면 **다시 뽑기**.
  - **음성(TTS)**: "○○님 당첨!" 다음에 당첨자 채팅을 한국어 목소리로 읽어요 (Windows 기본 음성). 패널의 **목소리 테스트**로 먼저 들어 보세요.
  - 미리보기: 패널의 미리보기 버튼 (`/draw?demo=1&n=40&w=2&seed=7`), **테스트 참가자**로 연습.

## 업데이트 방법
Allmind 설정 창 → **업데이트** → **지금 업데이트** (방송·녹화 중이 아닐 때). 그다음 Xylem 창에서 새 팩이 보이면 **지금 적용**.
